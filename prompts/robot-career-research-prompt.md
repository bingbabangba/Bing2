# 로봇 대기업 취업 역설계 — 리서치 프롬프트

석사 입학 시점에서 "수도권 로봇 관련 대기업 취업"을 목표로, 직무를 먼저 정하고 그에 맞춰 활동을 역설계하기 위한 조사 프롬프트 모음.

## 사용법

1. **웹 검색이 되는 딥리서치 모드**에서 실행한다 (ChatGPT Deep Research, Gemini Deep Research, Claude Research 등). 검색 없이 돌리면 채용 공고·논문·수치를 지어낼 위험이 크다.
2. `# 내 정보` 칸을 최대한 채운다. 특히 **연구실 분야, 졸업 예정 시기, 병역** 세 가지가 직무 추천과 로드맵을 크게 바꾼다.
3. 한 번에 돌려도 되지만, 역설계 취지대로라면 **2단계 실행**을 권장한다 (아래 2번 참고): 직무 추천까지 받고 → 직접 직무를 확정한 뒤 → 논문·활동·로드맵을 받는다.
4. 결과의 '확인 필요' 항목과 채용 요건은 반드시 공식 채용 사이트에서 직접 다시 확인한다.

## 1. 마스터 프롬프트 (한 번에 실행)

```text
# 역할
너는 한국 로봇 산업과 대기업 R&D 채용 구조를 잘 아는 커리어 리서처이자, 로봇공학 석사과정 학생을 지도해 본 연구자다.
웹 검색으로 최신 정보를 직접 확인하고, 출처가 달린 '실행 가능한' 조사 보고서를 작성해라.

# 배경과 목표
- 나는 [20XX년 X월]에 석사과정을 시작하고, [20XX년 X월]에 졸업할 예정이다.
- 목표: 졸업 시점에 수도권(서울·경기·인천)에서 근무하는 로봇 관련 대기업의 R&D·엔지니어 직무에 신입으로 입사하는 것.
- 방법: 역설계(reverse engineering).
  ① 목표 기업·직무를 먼저 정하고 → ② 그 직무가 요구하는 역량을 분해한 뒤 → ③ 석사 2년간의 연구·논문·프로젝트·대외활동을 그 역량에 맞춰 설계한다.
- 따라서 이 보고서의 최종 산출물은 '목표 직무 추천'과 '그 직무에 맞춘 학기별 실행 계획'이다.

# 내 정보 (빈칸이 있으면 합리적인 가정을 세우고, 가정이라고 표시한 뒤 진행해라)
- 학부 전공:
- 석사 연구실 연구 분야 (지도교수의 주요 연구 주제):
- 관심 분야 (예: 휴머노이드, 매니퓰레이션, 이동로봇·자율주행, 제어, 로봇 AI):
- 현재 역량 (상/중/하): C++ / Python / ROS 2 / 선형대수·확률·최적화 / 제어이론 / 딥러닝 / 하드웨어·임베디드
- 프로젝트·연구 경험:
- 어학 성적:
- 병역 (미필이면 전문연구요원 고려 여부):
- 선호·기피 조건 (기업, 직무, 근무지 등):

# 조사 범위
- 수도권 대기업: 공정거래위원회 지정 대기업집단(공시대상기업집단) 계열사와 이에 준하는 대형 IT 기업. 본사가 지방이어도 로봇 관련 R&D 조직이 수도권에 있으면 포함하되, 실제 근무지를 반드시 확인해 적어라.
- 로봇 관련: 로봇 제품·플랫폼을 개발하는 조직뿐 아니라, 로봇을 생산·물류 자동화에 대규모로 적용하는 조직(각 그룹의 생산기술 조직 등)과 로봇 부품(액추에이터·센서·카메라 모듈 등)에 진출한 부품 계열사까지 포함.
- 시점: 정보는 오늘 기준 최신으로 조사하되, 판단은 내 졸업 시점(약 2~3년 뒤)의 채용 시장을 기준으로 해라.

# 조사 항목

## 1. 기업 조사
최소 아래 기업을 포함하고, 빠진 중요 기업이 있으면 추가해라.
삼성전자(로봇 관련 조직, 레인보우로보틱스 등 계열·투자사), 현대자동차그룹(현대차·기아·현대모비스·현대위아·현대로템, 보스턴다이나믹스와의 관계), LG전자(로봇 사업, 베어로보틱스 등 인수·투자사), 네이버(네이버랩스), 두산로보틱스, 한화그룹(한화로보틱스·한화에어로스페이스 등), HD현대그룹(HD현대로보틱스 등), 포스코그룹, SK그룹, LS그룹, CJ그룹, KT, LG유플러스, 쿠팡

기업별 정리 항목:
- 로봇 관련 조직명과 실제 근무지 (수도권 여부)
- 주력 로봇 제품·기술과 사업 방향
- 최근 2년 핵심 동향 (투자, M&A, 조직 개편, 신제품, 인력 확충)
- 로봇 관련 채용 직무와 실제 공고 예시 (공고명·시기·링크, 공고에 쓰인 직무명 그대로)
- 석사 신입 채용 경로 (공채, 상시채용, 석·박사 전형, 산학장학생, 채용연계형 인턴 등)
- 전형 절차 (서류, 인적성·코딩테스트, 직무·PT면접(연구 발표), 인성면접)와 어학 요건 — 공식 정보와 비공식 후기를 구분
- 전문연구요원 병역지정업체 여부
- 공고에서 반복되는 요구 역량 키워드
마지막으로 석사 신입 관점의 매력도(성장성, 채용 규모, 석사 채용 비중, 직무 다양성, 근무지)를 기준으로 기업을 1~3티어로 나누고 근거를 적어라.
수도권 밖 기업, 로봇 전문 중견기업·스타트업, 외국계 기업 중 플랜 B나 디딤돌로 의미 있는 곳은 별도의 짧은 표로 정리해라.

## 2. 직무 조사
로봇 관련 직무를 아래처럼 세분화해 비교해라 (필요하면 추가·병합).
로봇 SW(아키텍처·미들웨어·ROS 2·플릿 관제) / 로봇 제어(모션·힘·전신 제어) / 로봇 AI·로봇 러닝(강화학습·모방학습·VLA) / 인지·비전(3D 비전·센서 퓨전) / SLAM·내비게이션 / 매니퓰레이션·그래스핑 / 시뮬레이션·디지털 트윈 / 기구·하드웨어 설계(구동기·감속기·로봇 핸드) / 전장·임베디드·모터 드라이브 / 생산기술·자동화(로봇 적용) / 로봇 데이터(텔레오퍼레이션·데이터 파이프라인) / 시스템 통합·필드 엔지니어 / 안전·인증 / 기술 기획

직무별 정리 항목:
- 실제로 하는 일 (업무·프로젝트 예시)
- 필수·우대 역량과 기술 스택 (실제 채용공고 문구를 근거로 인용)
- 이 직무를 뽑는 기업 (1번 기업 중)과 채용 수요의 규모·추세
- 석사 신입의 경쟁력 (석사로 충분한지, 박사를 선호하는지)
- 연결되는 석사 연구 주제 예시
- 내 졸업 시점의 수요 전망과 리스크

반드시 포함할 것:
- 비교 매트릭스: 직무 × (채용 수요, 성장성, 석사 경쟁력, 내 배경 적합도, 2년 내 준비 가능성), 5점 척도와 점수 근거
- 추천: 주력 직무 1개 + 보조 직무 1개 (T자형 프로필)와 그 이유
- 추천 직무의 역량 분해도: 직무 → 필요 역량 → 그 역량을 증명할 산출물 (논문, 프로젝트, 대회, 오픈소스 기여 등)

## 3. 로봇 업계 동향
- 글로벌: 피지컬 AI·임바디드 AI, 휴머노이드, 로봇 파운데이션 모델(VLA), 월드 모델, 시뮬레이션과 sim-to-real, 데이터 수집(텔레오퍼레이션 등), 빅테크·스타트업·중국 기업의 최신 움직임
- 국내: 정부 정책(지능형 로봇 기본계획, 첨단로봇·휴머노이드·피지컬 AI 관련 전략과 민관 연합체, 예산), 대기업의 투자·M&A·협력, 로봇 인력 수요 전망, 한국 로봇 산업의 구조적 강점·약점 (로봇 밀도, 핵심 부품 해외 의존도, 중국과의 경쟁 등)
- 시장 데이터: IFR World Robotics 등 신뢰도 높은 최신 통계 (산업용, 협동로봇, 서비스, 물류, 국방, 의료·웨어러블 등 분야별)
- 사실(확정 수치)과 전망(예측치)을 구분하고, 과열(hype) 가능성도 평가해라.
- 결론: "그래서 2~3년 뒤 수도권 대기업이 가장 많이 뽑을 로봇 역량은 무엇인가"

## 4. 추천 직무에 맞춘 논문·학습 자료
2번에서 추천한 직무를 기준으로:
- 기초 교재·강의 (무료 온라인 강의 포함)
- 반드시 읽어야 할 고전·핵심 논문 5~10편
- 최근 2년 내 핵심 논문 10~15편
- 서베이 논문 2~3편
- 목표 기업·국내 연구기관 소속 저자의 논문이나 기술 블로그 (면접 대비용)
논문마다: 제목 / 저자 / 연도 / 학회·저널 / 링크(arXiv·DOI) / 코드 공개 여부 / 한 줄 요약 / 왜 읽어야 하는지 / 읽는 순서
추가로:
- 주요 학회·저널 (ICRA, IROS, RSS, CoRL, Humanoids, RA-L, T-RO 등과 국내 학회)과 투고 마감 시기
- 석사 2년 안에 현실적인 논문 실적 목표 (국내 학회 → 국제 학회·저널 단계)
- 효율적인 논문 읽기·정리 방법

## 5. 기타 필요한 정보와 하면 좋을 활동
아래 항목을 이름 / 주최 / 시기(최근 회차 기준) / 지원 자격 / 채용·가산점 연계 여부 / 링크 형식의 표로 정리해라.
- 공모전·경진대회 (국내·국제, 로봇·AI)
- 인턴십 (채용연계형, 기업 연구소, 해외 연구 인턴)
- 산학장학생·기업 장학 프로그램, 정부 인재양성 사업 (석사 인건비·해외 연수 지원 등)
- 학회·전시회·채용설명회·테크 포럼 (네트워킹 기회)
- 오픈소스 기여 대상과 포트폴리오(GitHub, 데모 영상, 기술 블로그) 구성법
- 채용 시험 준비: 기업별 코딩테스트 형태, 인적성, 어학 최소 요건, 기술면접·PT면접 빈출 주제
- 개인 프로젝트용 저비용 하드웨어·시뮬레이터
- 주요 기업의 석사 채용·산학장학생·인턴 모집 연간 캘린더 (월별)

## 6. 추가로 필요한 사항 (네 판단)
위에서 다루지 않았지만 내 목표에 중요한 것을 스스로 찾아 제시해라.
예: 병역(전문연구요원) 전략, 석사 후 취업과 박사 진학의 판단 기준, 연구실 주제와 목표 직무가 다를 때의 대응, 지도교수·연구실 자원 활용법, (연구실 미정이면) 연구실 선택 기준, 플랜 B (중견·스타트업·해외), 업계 리스크와 대비책, 석사 취업 준비생의 흔한 실패 패턴

# 최종 종합 (가장 중요)
- 학기별 역설계 로드맵: 1~4학기와 방학별 목표, 구체적 산출물, 채용 일정과의 정렬 (언제 무엇에 지원하는지)
- 당장 할 일: 이번 주 / 이번 달 / 첫 학기 체크리스트
- 진척도를 확인할 KPI (논문, 프로젝트, 대회, 코딩테스트, 어학 등)

# 작성 규칙
1. 반드시 웹 검색으로 최신 정보를 확인하고, 보고서 맨 위에 조사 기준일을 적어라.
2. 모든 사실 정보(수치, 채용 공고, 조직명, 정책, 논문)에 출처 링크와 날짜를 달아라. 공식 자료(채용 사이트, 보도자료, 정부 발표, IFR, 학회 페이지)를 우선하고, 커뮤니티·블로그 정보는 '비공식'으로 표시해라.
3. 확인하지 못한 정보는 '확인 필요'로 표시해라. 존재하지 않는 논문·공고·수치를 만들어내지 마라. 논문은 실제로 검색되는 것만 넣어라.
4. 사실 / 추정 / 의견을 구분해서 써라.
5. 일반론보다 구체적인 기업명·조직명·직무명·논문명·대회명·일정을 우선해라.
6. 비교는 표로 하고, 각 섹션 끝에 '나에게 주는 시사점'을 3줄로 붙여라.
7. 맨 앞에 10줄 이내의 핵심 요약을 넣어라: 추천 직무, 목표 기업 Top 5, 가장 중요한 활동 Top 5.
8. 맨 끝에 '확인 필요 항목'과 '내가 직접 확인해야 할 공식 페이지 링크' 목록을 붙여라.
9. 분량 제한에 걸리면 내용을 줄이지 말고 섹션 단위로 끊어라. 내가 '계속'이라고 하면 이어서 써라.
10. 한국어로 쓰고, 기술 용어는 영어를 병기해라.
```

## 2. 2단계로 나눠 실행할 때

**1단계** — 마스터 프롬프트 맨 끝에 아래 문장을 붙여 실행한다.

```text
이번에는 4~6번과 최종 종합은 생략하고, 1~3번과 2번의 직무 추천(비교 매트릭스, 추천 직무, 역량 분해도)까지만 작성해라.
```

**2단계** — 추천 결과를 보고 직무를 직접 확정한 뒤, 같은 대화에서 실행한다.

```text
앞의 보고서를 바탕으로 내 목표 직무를 [주력 직무] (보조: [보조 직무])로 확정했다. 확정 이유: [이유]
이 직무를 기준으로 처음 프롬프트의 4·5·6번과 최종 종합(학기별 로드맵, 당장 할 일, KPI)을 작성해라. 작성 규칙은 앞과 같다.
```

## 3. 후속 심화 프롬프트

### A. 목표 기업 딥다이브

```text
[기업명]의 로봇 관련 조직을 석사 신입 지원자 관점에서 심층 조사해라.
- 조직 구조, 주요 리더, 근무지
- 최근 3년간 로봇 관련 채용 공고 전수: 공고명, 시기, 직무명, 자격 요건·우대 사항 원문
- 기술 블로그, 발표, 논문, 특허로 본 핵심 기술 방향
- 협력 대학·연구실, 산학 과제
- 석사 신입 전형 절차와 면접 후기 (공식/비공식 구분)
- 이 회사가 좋아할 석사 연구 주제와 포트폴리오, 내가 지금부터 준비할 것 5가지
모든 사실에는 출처 링크와 날짜를 달고, 확인하지 못한 것은 '확인 필요'로 표시해라.
```

### B. 포트폴리오 프로젝트 설계

```text
내 목표 직무는 [직무], 목표 기업은 [기업]이다. 현재 역량: [역량 요약]. 사용 가능한 장비·예산: [장비/예산]
이 직무의 채용 담당자가 보자마자 역량을 확인할 수 있는 포트폴리오 프로젝트 3개를 난이도별(4주 / 8주 / 한 학기)로 설계해라.
프로젝트마다: 목표, 공고의 어떤 요구 역량을 증명하는지, 하드웨어·시뮬레이터, 기술 스택, 주차별 마일스톤, 결과물 형태(GitHub·데모 영상·기술 리포트), 예상 비용, 참고할 오픈소스·논문(실재하는 것만, 링크 포함)
```

### C. 12주 논문 읽기 커리큘럼

```text
내 목표 직무는 [직무], 연구 주제는 [주제]다. 12주 논문 읽기 커리큘럼을 짜라.
- 주차별 2편 (고전 1편 + 최근 2년 내 1편)
- 논문마다 핵심 질문 3개, 직접 해볼 재현·실습 과제, 주차별 산출물(요약 노트, 코드)
- 4주마다 그동안 읽은 논문을 엮은 미니 프로젝트 1개
실제로 존재하는 논문만 넣고, arXiv 또는 DOI 링크를 달아라.
```

### D. 분기별 로드맵 점검

```text
나는 지금 석사 [N]학기다. 원래 로드맵: [붙여넣기]
지금까지 한 것: [...] / 못 한 것: [...] / 새로 생긴 변수: [...]
최근 3개월의 로봇 업계·채용 시장 변화를 웹 검색으로 확인해 반영하고, 수정된 로드맵과 다음 3개월 우선순위 5개를 제시해라.
```

### E. 모의 기술면접

```text
너는 [기업] [직무] 석사 신입 채용의 기술 면접관이다. 내 연구 요약: [요약]
내 연구 발표(PT)를 들었다고 가정하고, 연구 내용 꼬리질문과 직무 기초 지식(기구학·동역학, 제어, 확률·최적화, 코딩 등) 질문을 섞어 한 번에 하나씩 총 10개를 던져라.
내가 답할 때마다 점수(5점 만점), 부족한 점, 모범 답안을 알려줘라.
```
