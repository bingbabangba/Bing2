# TSP 공정기술 학습 총정리

Nov 11, 2026 · @손예찬

## 1. 관통하는 흐름

**AI 시대의 병목은 계산이 아니라 데이터 이동이고, 미세화가 한계에 오자 칩을 패키지에서 나누고·붙이고·쌓고·촘촘히 잇는 쪽으로 성능의 무게가 옮겨왔다. 그럴수록 휘·열·정렬·청정 같은 기계적 허용 오차가 수율을 좌우한다.**

1. **원인:** AI 모델이 커지고 추론이 길어져 읽을 데이터(가중치, KV 캐시)가 폭증 → 메모리 월
2. **한계:** 칩을 작게 만드는 미세화가 물리(터널링·누설), 비용(EUV), 크기(레티클 상한), 수율(큰 칩일수록 급락)에 막힘 → Beyond Moore
3. **해법 네 동사:**
   - 나눈다: 칩렛, 양품 다이(KGD)만 골라 조립
   - 옆에 붙인다: 2.5D, 인터포저 (거리 mm)
   - 쌓는다: 3D, TSV·CoW·zHBM (거리 ㎛)
   - 촘촘히 잇는다: 와이어 → 범프 → 마이크로범프 → 하이브리드 본딩 (R·L·C 감소)
4. **대가:** 휘, 열, 정렬, 청정·평탄, 얇은 칩 핸들링, 곱셈 수율. 남는 문제는 기계·재료·열
5. **나:** 이 대가를 물리적으로 해석하고 개선하는 사람 = 기계공학 전공자의 자리

## 2. 기초 용어

패키지는 칩을 전기 연결·전력 공급·방열·보호하는 구조물이고, TSP 현직자는 이를 Electrical · Mechanical · Thermal 3대 특성으로 부릅니다.

| 용어 | 뜻 | 기억할 점 |
| --- | --- | --- |
| 웨이퍼 | 실리콘 원판 | 300mm, 두께 약 775㎛ |
| 다이 | 웨이퍼 위 회로 하나 또는 잘라 낸 조각 | 회로 영역 + I/O 패드 + 가장자리 보호띠(실 링). 다이 사이 길 = 스크라이브 라인 |
| 칩 / 베어 다이 | 다이를 넓게 부르는 말 / 패키지 전 맨 다이 | HBM·칩렛은 다이 상태로 조립 |
| 패키지 | 다이 + 기판 + 몰드 + 솔더볼 | 고객이 보드에 붙이는 완성품 |
| 서브스트레이트 (패키지 기판) | 칩의 미세 단자를 보드용 볼 간격으로 넓히는 다층 배선판 | 코어 + 빌드업층 + 비아. BT(메모리), FC-BGA(고성능). 패널 → 스트립 → 낱개로 두 번 잘림. 전공정에서는 '실리콘 기판'이라는 다른 뜻 |
| 리드프레임 | 금속 한 장으로 만든 저가형 뼈대 | 다이 패드, 이너·아우터 리드, 댐바. 몰드 후 잘라서 구부림(트림·폼). 메모리는 지금 대부분 BGA |
| 메인보드 PCB | 패키지들이 올라가는 제품 전체의 판 | 패키지 기판과 구분 |
| 스트립 | 패키지 자리 수십\~수백 개가 붙은 기판 판 | 레일·정렬 구멍. 스트립 단위로 공정 후 마지막에 절단 |

**층 순서 (2.5D, 위에서 아래):** 칩 → 인터포저 → 서브스트레이트 → 솔더볼 → 메인보드 PCB

**메모리 패키지의 '다리' 세 가지:** ① 범프(칩→기판, 플립칩·HBM) ② 와이어(칩→기판, 캐필러리) ③ 솔더볼(패키지→고객 보드, SBA 공정). ①②은 안쪽, ③은 바깥쪽 연결입니다.

## 3. 메모리·로직과 삼성 제품

SRAM은 로직 칩 안의 캐시, DRAM은 칩 밖의 작업 메모리, NAND는 전원을 꺼도 남는 저장 장치입니다.

|  | SRAM | DRAM | NAND |
| --- | --- | --- | --- |
| 구조 | 트랜지스터 6개(래치) | 트랜지스터 1 + 커패시터 1 | 절연막 사이 저장층에 전자를 가둠 (삼성 CTF) |
| 리프레시 | 불필요 | 필요 (온도↑면 더 자주) | 비휘발성 |
| 속도·밀도 | 가장 빠름, 셀이 큼 | 빠름, 고집적 | 느림, 초고집적 |
| 위치·예 | 로직 칩 안 캐시 | DDR5, LPDDR, GDDR, HBM | SSD, UFS, 메모리 카드 |
| 비유 | 손에 든 메모장 | 책상 위 | 책장 |

- **메모리 계층:** 레지스터 → SRAM 캐시(칩 안) → DRAM·HBM(칩 밖) → NAND. 칩 밖으로 나가는 순간 느려지고 전력이 듦 = 메모리 월의 원인
- **DRAM 규격:** DDR5(PC·서버, 하위 채널 2개, 모듈 위 PMIC, 칩 내 ECC) / LPDDR(저전력, 모바일·엣지) / GDDR(그래픽) / HBM(적층, 최대 대역폭). DDR = 클럭 오르고 내릴 때 두 번 전송
- **NAND:** 셀을 직렬로 이어 고집적. SLC\~QLC(한 칸에 1\~4비트). 3D V낸드(삼성 2013 최초 양산, 수백 층). 패키지는 계단식 다단 적층 + 와이어 본딩, 컨트롤러 함께(SiP)
- **로직 칩:** 계산·제어하는 칩(CPU, GPU, AP, NPU·AI 가속기, HBM 베이스 다이). 주로 파운드리 첨단 공정. HBM4부터 베이스 다이를 로직 공정(삼성 4나노)으로
- **LSI:** 원래 '대규모 집적'(SSI→MSI→LSI→VLSI). 삼성에서는 시스템LSI = 비메모리 칩 **설계** 사업부

**삼성전자 DS부문 (공개 자료 기준)**

| 조직 | 하는 일 | 제품 예 |
| --- | --- | --- |
| 메모리사업부 | DRAM·NAND 개발·생산 | HBM4·HBM4E, DDR5 RDIMM, LPDDR5X·LPDDR6·LPDDR5X-PIM, SOCAMM2, GDDR7, V낸드, SSD(PM1763, PM9E1), UFS 4.1 |
| 시스템LSI | 비메모리 칩 설계 | 엑시노스 2600, 아이소셀, DDI, PMIC, 보안칩 |
| 파운드리 | 위탁 생산 | 2나노·4나노 GAA, AI·HPC 칩, HBM4 베이스 다이 |
| TSP총괄 | 테스트·패키지 (온양·천안) | HBM 적층, 2.5D(Cube-S/E/R), 메모리 패키지 |

주요 사업장: 기흥·화성·평택(FAB), 온양·천안(TSP), 미국 텍사스(파운드리), 중국 시안(NAND)·쑤저우(테스트·패키지), 일본 요코하마 APL(패키지 연구, 2026.09 개소). DX부문은 갤럭시·TV·가전·네트워크.

## 4. 전공정 요약과 트렌드

전공정은 증착 → 노광 → 식각 → 세정을 층마다 반복하고 CMP로 평탄화하는 공정이며, 후공정은 그 결과물의 조건을 물려받습니다.

- **삼성 8대 공정:** 웨이퍼 제조 → 산화 → 포토 → 식각 → 증착·이온주입 → 금속배선 → EDS → 패키징
- **FEOL / BEOL:** 트랜지스터를 만드는 아래층 / 금속 배선을 깔는 위층. BEOL은 전공정 안의 단계로, 후공정(Back-end)과 다름
- **후공정이 물려받는 것:** 웨이퍼 두께, 약한 Low-k 절연막(다이싱 박리 원인), 패드, TSV, 잔류응력
- **트렌드:** GAA(게이트가 채널 4면을 감쌀, 삼성 3나노부터), High-NA EUV(개구수 0.33→0.55), 후면 전력 공급(BSPDN: 웨이퍼를 아주 얇게 갈고 뒷면 배선), 1c DRAM, 3D NAND 고단화, 웨이퍼 본딩

**미세화의 네 가지 한계**

1. 물리: 절연막이 얇아져 터널링·누설 전류 증가
2. 비용: EUV 장비와 공정 단계 증가로 개발비 폭증
3. 크기: 노광 장비가 한 번에 찍는 면적(레티클, 대략 26×33mm)에 상한
4. 수율: 칩이 클수록 결함을 맞을 확률이 커져 지수적으로 하락

양자 터널링은 배경의 일부일 뿐, HBM이 나온 직접 이유는 메모리 대역폭(메모리 월)입니다. 면접에서는 "미세화의 물리적·경제적 한계 + 메모리 병목" 두 축으로 말합니다.

## 5. 후공정 공정별 정리

TSP 공식 직무 설명의 공정(Back-Lap, Saw, CoW Bonding, Mold, Marking, Solder Ball Attach)과 테스트를 순서대로 정리했습니다.

| 공정 | 한 줄 설명 | 대표 불량·병목 |
| --- | --- | --- |
| EDS | 웨이퍼 상태로 칩마다 검사. ET·WBI → Hot/Cold → Repair → Inking. 프로브 카드, ATE, BIN | 프로브 마크, 접촉 불량, 과검·미검. HBM은 KGD 확보가 핵심 |
| 범핑 | 패드 위 금속 돌기. UBM → 포토 → 도금 → 리플로우. 백그라인딩 전 두꺼울 때 | 범프 높이 편차, 빠짐, 브리지, UBM 언더컷 |
| 백그라인딩 | 뒷면 연삭으로 얇게. DBG, 임시 캐리어 접합, Stress Relief | TTV, 휘, 크랙, 박막 핸들링 |
| 다이싱 | 블레이드 / 레이저 그루빙 / 스텔스 / 플라즈마. 작은 칩이 많으면 플라즈마 유리 | 칩핑(취성 파괴), 칩 플라잉(점착력 < 절단력·수압), Low-k 박리 |
| 다이 어태치·CoW | 이젝터·콜렛으로 픽업 → 정렬 → 접착(DAF) 또는 열압착(TC 본더) | 정렬 오차, 기울기, 보이드, 위층 누적 불량, 낮은 UPH |
| 와이어 본딩 | 캐필러리(세라믹 관)로 칩 패드에 볼 본드, 기판 본드 핑거에 스티치. 계단 적층 시 칩끼리도 연결. 녹이지 않고 초음파·열·압력으로 고체 접합 | 볼 리프트, 넥 크랙, 와이어 스위핑, 캐필러리 마모, 긴 와이어의 높은 인덕턴스 |
| 플립칩·리플로우 | 범프로 직결. 예열 → 소킹 → 피크(약 240\~250℃) → 냉각. 플럭스로 산화막 제거 | Non-wet, 브리지, 범프 크랙, 플럭스 잔류물 |
| 언더필 | 범프 사이를 에폭시로 채워 CTE 응력 분산. CUF / MUF | 침투 보이드, 코너 범프 피로 |
| 몰드 | EMC로 덮음. 트랜스퍼 / 컴프레션. 고성능 칩은 몰드 대신 금속 뚜껑 | 휘, 보이드, 와이어 스위핑, 박리 |
| 마킹 → SBA → 싱글레이션 | 레이저 각인 → 솔더볼 부착(BGA의 '다리') → 스트립을 몰드+기판째 절단 | 볼 빠짐·브리지, 구리 버, 가장자리 박리 |
| 패키지 테스트 | ATE + 핸들러 + 소켓. 번인(욕조 곡선 초기 고장 제거), MBT | 소켓 접촉 불량(재테스트 양품 = 과검), 테스트 시간 |
| 신뢰성 | TC(온도 사이클, 피로), 열충격, HTS, THB·HAST, MSL(팝콘), 낙하 |  |
| 검사 | AOI(결), X-ray(금속), SAT(경계면 박리), 단면·SEM |  |

**불량 분석 6단계**

1. 현상 정의: 어떤 불량이, 언제부터, 어느 장비·로트에서
2. 4M(+측정) 층별: 설비·자재·방법·사람·측정
3. 위치 패턴: 한쪽·가장자리에 몰리면 장비(온도 분포, 평행도, 흡착) 의심
4. 물리 확인: 비파괴(X-ray, SAT) → 파괴(단면, SEM)
5. 가설 검증: DOE
6. 개선·재발 방지: 조건 변경, SPC, 인터락, 표준화

불량은 공정을 따라 흐릅니다: BG 두께 편차 → 다이싱 입자 → 본딩 보이드 → 몰드 후 휘 → 테스트 BIN 불량. 그래서 앞뒤 공정 데이터를 함께 봅니다.

## 6. 재료·물리 개념

후공정 불량 대부분은 이 개념들로 설명됩니다. 기계공학 수업 내용과 그대로 이어집니다.

| 개념 | 핵심 | 패키지에서 |
| --- | --- | --- |
| CTE (열팽창계수) | Si 약 3, Cu 약 17, 유기 기판 약 15\~17 ppm/℃ | 휘, 범프 피로, TSV 구리 돌출. 하이브리드 본딩은 구리 팽창을 접합에 이용 |
| 에폭시 | 경화제와 반응해 3차원 그물이 되는 열경화성 수지. 접착력·절연·낮은 수축 | EMC, 언더필, DAF, NCF, 기판 모두 에폭시 계열. 약점: 흡습, 높은 CTE, 취성, 이온 불순물, 낮은 열전도 |
| EMC 조성 | 에폭시 + 경화제 + 실리카 필러(대부분) + 커플링제 + 카본블랙 등 | 필러↑ → CTE↓, 점도↑ (트레이드오프) |
| Tg (유리전이온도) | 넘으면 말랑해지고 CTE가 몇 배로 | 리플로우 중 휘 방향 반전, 고온에서 언더필 약화 |
| B-스테이지 / 겤화점 | 반경화 상태로 공급 / 더 안 흐르는 시점 | 냉장 보관·해동 관리, 겤화 전에 다 채워야 미충전 없음 |
| 잔류응력 | 외력 없이 남은 응력. 열팽창 차이, 경화 수축, 가공 손상, 막 응력. σ ≈ E×Δα×ΔT | 휘, 크랙, 박리. 접합 온도를 낮추면 감소(무응력 온도) |
| 열충격 | 급격한 온도 변화 → 물체 안 온도 차이 → 순간 파괴 | 온도 사이클(천천히, 재료 간 차이, 피로)과 구분. 리플로우 승온 속도, 레이저, 유리 기판 |
| 급냉 | 핵생성↑ → 솔더 조직 미세·균일 | 대신 열충격·잔류응력·휘·보이드 → 적정 냉각 속도 (강 담금질과 같은 구조) |
| 열저항 | R = L / (kA). 얇을수록 열이 잘 빠짐 | 실리콘보다 열전도가 수백 배 낮은 고분자 접합층이 진짜 병목 → 하이브리드 본딩 |
| 플럭스 | 산화막 제거, 재산화 방지, 젖음 향상 | 부족 → Non-wet / 잔류물 → 부식·보이드·박리 → 무플럭스·하이브리드 본딩으로 |

**R·L·C (기계 비유: 댐퍼·질량·스프링)**

- **인덕턴스 L:** 전류 변화에 저항하는 '관성'. V = L×di/dt. 길고 가는 배선일수록 큼 (와이어 약 1nH/mm 어림값)
- **리액턴스:** X\_L = 2πfL(주파수↑ → 커짐), X\_C = 1/(2πfC)(주파수↑ → 작아짐). 고속일수록 와이어가 불리
- **커패시턴스 C:** 전하 저장 능력. C = εA/d. 기생 C는 RC 지연·전송 전력(∝ CV²)·크로스톡 → Low-k·짧은 배선 / 디커플링 커패시터는 일부러 둠 / DRAM 셀 자체가 커패시터
- **그라운드 바운스:** 동시 스위칭 → L×di/dt로 접지 흔들림 → 전원·접지 단자 병렬·디커플링
- **임피던스 매칭:** 임피던스가 급변하면 신호 반사 (SAT가 박리를 찾는 원리와 같음)
- **요약:** 짧고 촘촘한 연결 = R·L·C가 모두 작아짐 → 속도↑, 전송 에너지↓. 칩을 얇게 갈면 TSV도 짧아짐

수치는 재료·조건마다 다른 어림값입니다.

## 7. 패키지 구조와 접합법

패키지는 두 축으로 나눕니다. \*\*무엇 위에 무엇을 붙이나(구조)\*\*와 \*\*어떻게 붙이나(접합법)\*\*는 서로 독립입니다.

**구조**

| 이름 | 위 / 아래 | 강점 | 과제 | 예 |
| --- | --- | --- | --- | --- |
| CoC | 칩 / 칩 | 양품만 골라 쌓기 | 작은 칩 핸들링, 느림 | 초기 TSV 적층 |
| CoW (D2W) | 칩 / 웨이퍼 | 수율과 생산성 절충 | 웨이퍼 휘·온도 분포 | **삼성 HBM** |
| WoW (W2W) | 웨이퍼 / 웨이퍼 | 가장 빠름 | 불량끼리도 붙음 | 이미지센서, zHBM 언급 |
| PoP | 패키지 / 패키지 | 따로 테스트 후 조립 | 위아래 휘 불일치 | 스마트폰 AP + LPDDR |
| 2.5D | 여러 칩 / 인터포저 | 열·설계 유연성 | 인터포저 비용·크기·휘 | HBM + GPU (Cube-S, 구 I-Cube) |
| 2.3D | 칩 / 브리지 또는 RDL | 비용·크기 | 배선 밀도 낮음 | Cube-E(브리지), Cube-R(RDL) |
| 3D | 칩 / 칩 수직 (TSV) | 거리 최단, 밀도 최고 | 열 갇힘, 곱셈 수율, 공동 설계 | HBM 내부, zHBM (3D Cube-T/H, 구 X-Cube) |

특히 HBM + GPU는 **내부는 3D, GPU와는 2.5D**입니다. CoWoS는 TSMC의 2.5D 브랜드입니다.

**접합법**

| 방법 | 원리 | 강점 | 과제 |
| --- | --- | --- | --- |
| 와이어 본딩 | 금·구리선을 초음파+열+압력으로 | 저비용, 유연 | 연결 수·속도 한계 |
| 매스 리플로우(MR) | 한꺼번에 녹여 붙임 | 생산성, 자기 정렬 | 휘에 약함 |
| TCB (열압착) | 칩마다 누르며 가열 | 휘 억제, 미세 피치 | 느림 |
| **TC-NCF (삼성)** | TCB + 미리 붙인 비전도성 필름 | 얇은 칩 휘 억제, 간격 균일 | 층마다 가열·가압 → UPH, 필름 두께·방열 |
| MR-MUF (SK하이닉스) | 가접합 후 일괄 리플로우 + 액상 몰드로 채움 | 생산성, 낮은 압력, 자기 정렬, 방열 | 고단·박형 휘, 좁은 틈 충전 |
| LAB (레이저 보조) | 레이저로 칩만 국부 가열 | 기판 휘 감소 | 국부 열충격 |
| 하이브리드 본딩 | 범프 없이 Cu–Cu + 절연막–절연막 | 피치 수 ㎛ 이하, 높이↓, 방열↑ | 초청정·초평탄·정렬, 투자 |

**범프 진화:** 솔더볼(0.4\~1mm) → C4 범프(약 150\~200㎛) → 구리 필러(약 40\~100㎛) → 마이크로범프(수십 ㎛) → 범프 없음(수 ㎛ 이하). 구리 필러는 솔더가 옆으로 퍼져 생기는 브리지를 막습니다.

**TC-NCF vs MR-MUF:** 휨 억제와 생산성 사이에서 다른 선택. 둘 다 다음 단계로 하이브리드 본딩을 보는 중. 면접에서 한쪽을 낙추지 않기.

**FOWLP (팬아웃 웨이퍼 레벨):** 양품 칩을 캐리어에 간격을 두고 배치 → 몰드로 재구성 웨이퍼 → 캐리어 분리 → RDL을 몰드 영역까지 펼침 → 볼 → 절단. 기판이 없어 얇고 경로가 짧음. 과제는 다이 시프트, 재구성 웨이퍼 휘, RDL 수율. 패널로 키우면 FOPLP.

## 8. 최신 기술

최신 기술은 모두 '더 가깝게, 더 촘촘하게'의 연장이고, 그 중심에 HBM이 있습니다.

### HBM

- DRAM을 TSV로 수직 적층하고 GPU 바로 옆 인터포저에 둔 메모리. 핀당 속도는 GDDR보다 낮지만 통로가 아주 많아 대역폭 최대
- I/O 폭: 1,024-bit → HBM4 2,048-bit. 적층 8→12→16단
- 삼성 HBM4 (2026.02 양산 출하): 1c DRAM + 4나노 로직 베이스 다이, 12단 36GB, 11.7Gbps(최대 13Gbps). HBM4E는 SEDEX 2026 실물 전시, 3분기 실적에서 양산 계획 언급
- 병목 다섯: 높이 규격, 휘, 열, 곱셈 수율, 생산성(UPH)

### TSV (Via-Middle)

1. 깊은 구멍 식각 (플라즈마)
2. 절연막(라이너) → 장벽막·씨앗층
3. 구리 전기도금 → CMP → 열처리
4. BEOL 배선 → 앞면 마이크로범프 (여기까지 두꺼운 상태)
5. 뒤집어 캐리어에 임시 접합 → 백그라인딩
6. TSV 노출(실리콘만 식각) → 보호막 → 뒷면 패드
7. 캐리어 분리 → 다이싱 → CoW 적층

대표 불량: 구리 채움 보이드, 구리 돌출(CTE 차이), TSV 주변 응력(회로 금지 구역), 노출 높이 편차, 박막 휘·크랙.

### 하이브리드 본딩 (D2W)

1. CMP: 구리 패드를 절연막보다 수 nm 들어가게 평탄화
2. 박막화·절단: 플라즈마·레이저 다이싱 (입자 최소화)
3. 세정 → 4. 플라즈마 표면 활성화 (접합까지 시간 제한)
4. 정렬 → 상온 접합: 절연막끼리 즉시 붙음
5. 열처리: 구리가 팽창해 틈을 메우고 Cu–Cu 결합
6. 다음 층 적층 → 8. SAT·IR 검사

핵심은 '붙기 전 표면': 초평탄(CMP), 초청정(입자 하나 = 텐트 보이드), 초정밀 정렬, 열처리 응력. 삼성은 이를 위해 플라즈마·레이저 다이싱과 CMP를 핵심으로 꼽음(보도 기준). 플럭스 불필요.

### 그 밖의 키워드

- **zHBM (삼성 개발 중):** AI 칩 위에 HBM을 직접 적층. WoW + 하이브리드 구리 본딩, 촘촘한 TSV. 과제는 AI 칩 열이 메모리를 통과하는 열 관리와 고객 칩과의 공동 설계
- **유리 기판 / 패널 레벨:** 평탄·CTE 조절·미세 배선 / 대면적 원가. 과제는 취성·대면적 휘. 요코하마 APL(2023 설립, 5년간 400억 엔, 2026.09 개소)이 웨이퍼 본딩·유리기판 연구 계획
- **CPO, zNAND-O:** 광 연결 동시 패키지 / V낸드 수직 적층 (SEDEX 2026 전시)
- **AI 반도체:** 계산(GPU·NPU·ASIC·CPU) + 메모리(HBM·DDR5·LPDDR·SSD) + 연결의 묶음. 학습 vs 추론, 데이터센터(HBM) vs 엣지(LPDDR, Jetson 같은 모듈)
- **자동화:** 후공정은 운반 형태가 계속 바뀌고 다품종이라 덜 자동화됐으나, 웨이퍼 단위 공정·얇은 칩·청정도 때문에 빠르게 자동화 중(세메스 테스트 무인화 보도, 직무 설명의 계측·검사 자동화)

### 전·후공정 경계 붕괴

- 연결 간격이 ㎛ 아래로 내려가며 가운데에 **중간 공정**(범핑, RDL, TSV, 임시 접합, 하이브리드 본딩, 플라즈마 다이싱)이 생김
- 전공정 → 후공정: CMP·포토·도금·플라즈마, 초청정, ㎛ 이하 정렬
- 후공정 → 전공정: 웨이퍼 본딩, 후면 전력의 박막화·임시 접합
- 제품 융합: HBM4 = 메모리(1c DRAM) + 로직(4나노 베이스 다이) + 패키징. 삼성 "메모리부터 첨단 패키징까지 아우르는 세계 유일의 IDM", 3분기 파운드리 실적에 'HBM 베이스 다이 매출 성장' 명시
- 의미: 공정기술 엔지니어도 앞뒤 공정·설계를 함께 이해하고 공정 간 데이터를 연결해야 함

그림: `T9/그림/` 1–3(2.5D vs 3D, HBM·zHBM, Cube-S/E/R), 6(경계 붕괴), 7(TSV), 8(하이브리드 본딩)

## 9. 수율과 칩 크기

결함은 무작위로 떨어지므로 칩이 클수록 수율이 지수적으로 떨어지고, 그래서 큰 칩을 나눠 패키지에서 합칩니다.

```latex
Y = e^{-D \cdot A}
```

D = 단위 면적당 결함 수, A = 칩 면적. D = 0.1개/cm² 가정 시 1cm² 약 90%, 4cm² 약 67%, 8cm² 약 45%. 큰 칩은 웨이퍼 가장자리 손실도 큽니다.

- **칩렛·HBM:** 작게 나눠 칩마다 수율을 높이고, 양품(KGD)만 골라 조립
- **대가 = 곱셈 수율:** 칩당 99%라도 12단이면 0.99¹² ≈ 88.6%, 16단이면 ≈ 85.1%. 조립 공정 안정성(TSP)이 핵심
- **CoC·CoW·WoW:** 수율은 CoC, 생산성은 WoW, CoW는 절충
- **다이싱과 크기:** 작은 칩은 자를 길이 많고 날아가기 쉬움 → 모든 길을 동시에 자르는 플라즈마가 유리. 큰 칩은 휘·크랙 위험
