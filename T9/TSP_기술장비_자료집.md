# TSP 기술·장비 자료집

Nov 6, 2026 · @손예찬

## 1. TSP는 무엇을 하나 — 삼성 공식 설명 기준

**한 줄 정의:** TSP(Test & System Package)총괄은 웨이퍼 상태로 넘어온 칩을 **테스트 → 개별 칩으로 분리 → 기판에 붙이고 연결 → 보호(몰드) → 최종 테스트**까지 해서 '고객이 쓸 수 있는 제품'으로 만드는 조직입니다. 사업장은 **온양(아산)·천안**입니다.

### 1-1. 패키지의 4대 역할 (삼성 반도체 뉴스룸 '8대 공정 9탄')

| 역할 | 뜻 | 면접에서 쓰는 말 |
| --- | --- | --- |
| 상호 배선 | 칩의 미세 전극을 메인보드 수준의 크기로 연결 | "신호가 나가는 길을 만든다" |
| 전력 공급 | 칩에 전원을 안정적으로 전달 | "전기가 들어오는 길을 만든다" |
| 방열 | 칩에서 나는 열을 밖으로 뺀다 | "열이 빠지는 길을 만든다" |
| IC 보호 | 습기·충격·오염으로부터 보호 | "칩을 지키는 집을 만든다" |

> 💡 기계공학 연결: 4가지 중 **방열·보호(구조)는 열전달·재료역학**, 상호 배선은 접합(솔더·와이어)의 **기계적 신뢰성** 문제입니다. "패키지는 전기·열·기계가 동시에 걸리는 다물리(multiphysics) 구조물"이라고 말하면 기계과 강점이 바로 드러납니다.

### 1-2. 공식 직무 설명 (삼성전자 DS 채용 직무소개 — TSP 공정기술)

- **Package 양산 공정 개선:** Back-Lap, Saw, CoW Bonding, Mold, Marking, Solder Ball Attach 공정의 수율·품질·생산성 개선
- **Test 공정 개선:** 테스트 공정 효율화, 테스트 시간·비용 절감
- **공정 기반 기술:** 신규 공정/소재/장비 평가 및 도입
- **자동화 계측·검사:** 계측·검사 자동화, 데이터 기반 공정 관리
- 최근 키워드: **HBM, 2.5D 패키지** 양산 대응

> ✅ 정리하면 공정기술 엔지니어의 일 = **"정해진 공정을 매일 같은 품질로 돌아가게 하고(양산 관리), 문제가 생기면 원인을 찾아 고치고(불량 분석·개선), 새 장비·소재를 검증해서 들여오는 것(신규 도입)"**.

### 1-3. 전체 흐름 한눈에

```
[FAB 완료 웨이퍼]
   ↓ EDS 테스트 (웨이퍼 상태로 칩별 양/불 판정, BIN 분류)
   ↓ Back-Lap / Back Grinding (웨이퍼 뒷면 갈아서 얇게)
   ↓ Saw / Dicing (칩 단위로 자르기)
   ↓ Die Attach / CoW Bonding (기판 또는 웨이퍼 위에 칩 붙이기·쌓기)
   ↓ Interconnect (Wire Bond 또는 Flip Chip + Reflow + Underfill)
   ↓ Mold (EMC로 덮어 보호)
   ↓ Marking (레이저로 제품 정보 각인)
   ↓ Solder Ball Attach (보드 연결용 볼 부착)
   ↓ Singulation (패키지 단위로 자르기)
   ↓ Package Test / Burn-in (최종 전기·신뢰성 테스트)
[출하]
```

### 1-4. 왜 지금 TSP가 중요한가

- 반도Chat Ep.7(2024.02): 미세화 난이도·비용이 기하급수적으로 증가 → **'Beyond Moore'** 대안으로 서로 다른 칩을 수평·수직으로 연결하는 \*\*첨단 패키지(이종 집적화)\*\*가 핵심 경쟁력.
- 삼성 반도체 기술 블로그(AVP): "첨단 패키징은 더 이상 단순한 후공정 조립 단계가 아니라, 차세대 컴퓨팅 시스템 설계를 좌우하는 **핵심 아키텍처 계층**" — AI 시대 병목은 데이터 이동(메모리 대역폭)과 열.
- 실제 투자: **온양 사업장 첨단 패키지 라인 투자**(클린룸 약 9,400평, 2026 하반기 착공·2029년 5월 양산 목표, 보도 기준).

## 2. 조립(Assembly) 공정별 기술·장비

각 공정을 **목적 → 방법 → 대표 장비 → 대표 불량 → 관리 변수 → 기계공학 연결** 순으로 정리했습니다. 면접에서 "OO 공정 아느냐"를 받으면 이 순서대로 답하면 됩니다.

### 2-1. Back-Lap / Back Grinding (BG, 백랩)

- **목적:** FAB에서 온 웨이퍼(약 775㎛)를 패키지 두께에 맞게 얇게. HBM 코어 다이는 수십 ㎛ 수준까지 갈아야 12단·16단을 정해진 높이(JEDEC 규격) 안에 넣을 수 있음.
- **방법:** 앞면에 보호 테이프(BG tape) 부착 → 뒷면을 다이아몬드 휠로 차례대로 연삭(추삭→정삭) → 연삭 손상층 제거(Stress relief: 폴리싱/건식식각). 얇은 웨이퍼는 캐리어(임시 지지체)에 붙여 가공하기도 함.
- **변형:** DBG(Dicing Before Grinding) — 먼저 반만 자르고 갈아서 자연스럽게 분리. 얇은 칩의 치핑·크랙 감소.
- **대표 장비:** 그라인더(디스코 등), 테이프 라미네이터, 폴리셔.
- **대표 불량:** 두께 편차(TTV), 휘어짐(Warpage), 크랙·치핑, 연삭 자국(스크래치).
- **관리 변수:** 휠 회전수·이송속도, 케이크(척) 평탄도, 냉각수, 최종 두께.
- 🔧 **기계 연결:** 절삭·연삭 가공(기계가공량 수업), 잔류응력과 휘어짐 = 재료역학, TTV = 기하공차.

### 2-2. Saw / Dicing (쏯·다이싱)

| 방식 | 원리 | 장점 | 단점 / 비고 |
| --- | --- | --- | --- |
| Blade dicing | 다이아몬드 블레이드로 절단 | 가장 보편적, 저비용 | 치핑·입자 발생, 열·진동 |
| Laser grooving | 레이저로 표면 배선층(Low-k)을 먼저 홈 파고 블레이드 절단 | Low-k 박리 방지 | 열영향부(HAZ) |
| Stealth dicing | 레이저를 웨이퍼 내부에 초점 → 개짎는 층 생성 후 테이프 확장으로 분리 | 입자·물 없음, 얇은 웨이퍼에 유리 | 금속층이 있으면 제약 |
| Plasma dicing | 건식식각으로 스크라이브 라인을 한꺼번에 식각 | 치핑·입자 거의 없음, 칩 강도↑ | 장비비·마스크 공정 필요 |

- **최신 동향(시사저널e 2025.02.18, ITF Korea 발표):** 삼성은 **하이브리드 본딩(HCB)** 도입을 위해 기존 블레이드 다이싱을 **레이저 그루빙·플라즈마 다이싱**으로 바꾸는 방안을 검토. 하이브리드 본딩은 범프 없이 칩 표면끼리 붙이므로 **미세 입자 하나가 공동(void)·접합 불량**이 되기 때문. 같은 발표에서 \*\*CMP(화학적 기계 연마)\*\*가 핵심 공정으로 언급됨(표면 평탄도·구리 패드 높이 제어).
- **대표 불량:** 치핑(앞/뒷면), 크랙, 다이 표면 오염·입자, 커프 폭 편차, 포지션 오차.
- **관리 변수:** 블레이드 회전수·이송속도·마모, 레이저 출력·초점, DI수 유량, 테이프 점착력.
- 🔧 **기계 연결:** 절삭이론, 파괴역학(치핑 = 취성재료 균열 진전), 진동, 블레이드 마모 예측.

### 2-3. Die Attach / CoW Bonding (다이 본딩 · 칩-온-웨이퍼 적층)

- **목적:** 잘라난 칩을 픽업해 기판/리드프레임/다른 칩·웨이퍼 위에 정확히 올리고 붙이기.
- **방법(일반 패키지):** 이젝터 핀으로 테이프 밑에서 밀어 올리고 → 콜렛(흡착 노즐)으로 픽업 → 비전으로 정렬 → 접착제(DAF 필름 또는 페이스트)로 부착 → 경화(Cure).
- **HBM의 CoW Bonding:** 베이스 다이 웨이퍼 위에 TSV 코어 다이를 한 층씩 쌓음. 삼성은 **TC-NCF**(열압착 + 비전도성 필름) 방식 — 4절 상세.
- **대표 장비:** 다이 본더, **TC 본더(열압착 본더)**, 헬이브리드 본더, 큐어 오븐 — 장비 업체는 5절.
- **대표 불량:** 정렬 오차(misalign), 접착층 보이드, 칩 기울어짐(tilt), 픽업 시 칩 크랙, 비접합(Non-wet)·브리지(인접 범프 단락).
- **관리 변수:** 본딩 온도·압력·시간(프로파일), 헤드–스테이지 평행도, 정렬 정밀도(㎛ 이하), UPH(시간당 생산량).
- 🔧 **기계 연결 (가장 직접적!):** 픽앤플레이스 = 로봇·메카트로닉스, 정렬 = 비전 기반 제어, 헤드 평행도 = 기구 설계. **로봇팔 정밀도 46→97점 경험**을 가장 자연스럽게 연결할 수 있는 공정.

### 2-4. Interconnect — Wire Bonding vs Flip Chip

| 항목 | Wire Bonding | Flip Chip |
| --- | --- | --- |
| 연결 | 칩 윗면 패드–기판을 금/구리 와이어로 연결 | 칩을 뒤집어 범프(솔더)로 기판에 직접 연결 |
| 장점 | 저비용·유연성, 성숙한 기술 | 경로 짧음 → 속도↑·I/O↑·방열↑ |
| 단점 | 경로 길고 I/O 수 제한 | 비용↑, 범프 신뢰성·언더필 필요 |
| 핵심 장비 | 와이어 본더(초음파+열+압력) | 플립칩 본더, 리플로우 오븐, 언더필 디스펜서 |
| 대표 불량 | 볼 리프트, 넥 크랙, 와이어 스위핑(몰드 시 와이어 휘어짐) | 범프 크랙, 논웬(Non-wet), 브리지, 언더필 보이드 |

- **삼성 뉴스룸(8대 공정 9탄):** 전통적으로 금선(gold wire)을 이용한 와이어 본딩이 쓰였고, 고성능 제품일수록 플립칩·TSV 같은 짧은 연결로 이동.
- **리플로우(Reflow):** 솔더를 녹였다 굳혀 접합. 온도 프로파일(예열→소킹→피크→냉각)이 핵심. Mass Reflow(MR)는 한꺼번에 가열.
- **언더필(Underfill):** 칩–기판 틈을 에폭시로 채워 **CTE(열팽창계수) 차이로 생기는 열응력을 분산** → 범프 피로 수명 연장. 모세관 현상으로 흘러들어감(CUF) 또는 몰드와 동시(MUF).
- 🔧 **기계 연결:** 솔더 피로(Coffin-Manson), 열응력 σ ≈ E·Δα·ΔT, 모세관 유동(유체역학), 초음파 접합.

### 2-5. Mold (몰딩)

- **목적:** 칩과 연결부를 \*\*EMC(Epoxy Molding Compound)\*\*로 덮어 외부 환경·충격으로부터 보호.
- **삼성 뉴스룸 설명:** EMC를 가열해 젤(gel) 상태로 만든 뒤 금형에 부어 굳힘.
- **방식:** Transfer Molding(수지를 러너로 밀어 넣음, 전통) vs **Compression Molding**(수지를 깔고 위에서 눌러 성형 → 와이어 스위핑 적음, 웨이퍼·대형 패널에 유리). MUF(Molded Underfill)는 언더필과 몰드를 한번에.
- **대표 불량:** 보이드, 미충전(Incomplete fill), 와이어 스위핑, **휘어짐(Warpage)**, 박리(Delamination), 플래시(수지 넘침).
- **관리 변수:** 금형 온도, 성형 압력·시간, EMC 점도·필러 함량, 진공도, 후경화(PMC) 조건.
- 🔧 **기계 연결:** 사출성형과 거의 같은 원리(유동·경화·금형 설계), 휘어짐 = 이종재료 적층보(바이메탈) 열변형, Moldflow 같은 CAE 해석.

### 2-6. Marking → Solder Ball Attach → Singulation

- **Marking:** 레이저로 몰드 표면에 제품명·로트·추적 코드 각인. 불량: 깊이 불만족, 판독 불가 → 비전 검사(OCR)로 확인. 추적성(Traceability) 관점에서 중요.
- **SBA(Solder Ball Attach):** 기판 패드에 플럭스 도포 → 볼 올림(볼 마운트, 스텐실/볼 마스크) → 리플로우 → 세정. BGA 패키지의 "다리". 불량: 미부착(Missing ball), 브리지, 볼 높이·동평도(Coplanarity) 불량.
- **Singulation:** 스트립(많은 패키지가 붙어있는 기판)을 개별 패키지로 절단(블레이드 쏘 또는 레이저). 선별(Sorting) 후 트레이에 적재.
- **장비 예시:** 한미반도체의 \*\*micro SAW & Vision Placement(MSVP)\*\*는 절단·세정·건조·비전검사·적재를 한 장비에서 수행하는 반도체 패키지 후반 장비로 소개됨(이코노미리뷰, SEDEX 2026 보도 기준).
- 🔧 **기계 연결:** 동평도 = 기하공차, 볼 전단강도 시험(Ball Shear Test), 낙하·진동 시험 = 동역학.

## 3. 테스트(Test) — EDS부터 최종 테스트까지

> 핵심 메시지: 테스트는 불량을 걸러내는 것에 그치지 않고, **테스트 데이터를 앞 공정에 되돌려 주는 피드백 루프**입니다(삼성 뉴스룸 8대 공정: 패키지 테스트 결과를 각 공정에 피드백해 품질 개선에 활용).

### 3-1. EDS (Electrical Die Sorting) — 웨이퍼 상태에서

- **목적:** 웨이퍼 위 각 칩의 양/불을 판정해 불량 칩에 패키지 비용을 쓰지 않게 하고, 수선 가능한 칩은 살리고, 결과를 FAB에 피드백.
- **흐름 (삼성 뉴스룸 8대 공정 EDS편):**
  1. **ET Test & WBI(Wafer Burn-In):** 전기적 특성 검사 + 고온·고전압 스트레스로 잠재 불량 조기 발견
  2. **Hot/Cold Test:** 고온·저온에서 동작 확인, 수선(Repair) 가능 여부 판단
  3. **Repair:** 레이저로 퓨즈 끊어 불량 셀을 여분(redundancy) 셀로 대체 → 다시 검사
  4. **Inking:** 불량 칩 표시(과거 잉크 → 현재는 데이터 맵(웨이퍼 맵)으로 관리)
- **핵심 하드웨어:** **프로브 카드**(미세 바늘로 칩 패드에 접촉), **프로버**(웨이퍼 이송·정렬), **테스터(ATE)**(신호 인가·측정).
- **BIN:** 칩을 결과에 따라 번호로 분류(양품 BIN, 불량 유형별 BIN). BIN 분포를 보면 어느 공정이 문제인지 역추적 가능.
- **관리 포인트:** 프로브 마크(패드 손상) → 이후 본딩 불량 유발, 프로브 팁 오염·마모, 접촉 저항, 온도 균일성.
- 🔧 **기계 연결:** 프로브 바늘의 오버드라이브(접촉력) = 외팔보 처짐, 프로브카드 열변형(고온 테스트 시 정렬 틀어짐) = 열팽창.

### 3-2. 패키지 테스트 (Final Test) — 조립 후

- **삼성 뉴스룸 설명:** 전압·신호·온도 조건을 바꿔가며 **전기적 특성, 기능, 동작 속도**를 검사.
- **Burn-in:** 고온·고전압으로 장시간 가동해 \*\*초기 고장(Infant mortality)\*\*을 출하 전에 걸러냄 → '욕조 곡선(Bathtub curve)'의 앞부분을 잘라내는 것.
- **MBT(Monitoring Burn-in Test):** 번인 중에 동작까지 모니터링해 번인+테스트를 동시에 → 테스트 시간 단축.
- **장비 구성:** **ATE(테스터)** + **핸들러**(패키지를 소켓에 넣고 빼고 결과별로 분류하는 로봇) + **소켓/테스트 보드**(패키지와 테스터를 전기적으로 잇는 접점) + 번인 보드/챔버.
- **평가 지표:** 수율(Yield), **Test Time / 동시 측정 수(Parallelism)**, 핸들러 UPH·잼(jam)률, 소켓 수명·접촉 불량률, 재테스트율.
- **최신 동향:** 세메스가 SEDEX 2026에서 **후공정 테스트 무인화(자동화) 설비**와 자동 물류(AMHS) 기술을 소개(이코노미리뷰 보도). 공식 직무기술서의 '테스트 비용 절감·자동화'와 같은 방향.
- 🔧 **기계 연결:** 핸들러 = 픽앤플레이스 로봇 + 온도 챔버(열제어) — **로봇팔·AGV 경험이 그대로 연결**되는 장비. 대량 생산에서 잼률 1% 감소 = 가동률 크게 상승.

### 3-3. HBM에서 테스트가 더 중요한 이유 — KGD

- HBM은 12\~16개 칩을 쌓으므로, 칩 하나가 불량이면 스택 전체가 불량. 수율이 곱으로 떨어짐 (예: 칩당 99% × 12단 ≈ 88.6%).
- 따라서 쌓기 전에 \*\*KGD(Known Good Die, 검증된 양품 칩)\*\*를 확보하는 것이 핵심 → 웨이퍼 레벨 테스트의 정확도가 수율을 좌우.
- 삼성 I-Cube4 보도자료(2021): 제조 공정 **중간에 테스트를 넣어 불량을 걸러내는 방식**으로 수율·생산성을 높였다고 설명 — "테스트를 어디에 넣느냐"도 공정 설계의 일부.

## 4. 첨단 패키지 — HBM·2.5D·3D

### 4-1. 용어 지도 (삼성 반도Chat Ep.7 기준)

- **이종 집적화(Heterogeneous Integration):** 메모리, 시스템 반도체 등 서로 다른 기능의 칩을 하나의 칩처럼 동작하게 묶는 기술.
- **2.5D 패키지:** 로직과 메모리를 **인터포저** 위에 수평으로 나란히 배치.
- **3D 패키지:** 칩을 수직으로 적층.
- **인터포저(Interposer):** 칩과 기판 사이의 '중간 배선판'. 칩끼리를 초미세 배선으로 연결(실리콘 / RDL(유기물) / 실리콘 브리지).
- **TSV(Through Silicon Via):** 칩에 수직 구멍을 뚫어 구리로 채운 엘리베이터 같은 전극. 와이어 대신 칩 상·하를 직접 연결.
- **RDL(Redistribution Layer, 재배선층):** 칩 패드 위치를 다시 배열하는 얇은 배선층.

### 4-2. HBM 구조와 삼성의 적층 기술

```
   [코어 다이 #12]   ← DRAM 칩 (TSV 관통)
   [  ...         ]
   [코어 다이 #1 ]
   [베이스(로직) 다이] ← GPU와 통신하는 인터페이스 칩
 ===== 인터포저 ===== GPU 옆에 나란히 (2.5D)
 ======= 패키지 기판 =======
```

| 방식 | 원리 | 사용 | 포인트 |
| --- | --- | --- | --- |
| **TC-NCF** (Thermo-Compression + Non-Conductive Film) | 칩 사이에 비전도성 필름을 넣고 한 층씩 열·압력으로 본딩 | **삼성** (마이크론도 유사) | 휘어짐 제어 유리, 필름 두께·방열이 과제 → 필름 박막화로 개선 |
| **MR-MUF** (Mass Reflow + Molded Underfill) | 칩을 가접합 후 한꺼번에 리플로우, 액체 언더필로 채움 | SK하이닉스 | 생산성·방열 유리, 고단에서 휘어짐 관리가 과제 |
| **Hybrid Copper Bonding (HCB)** | 범프 없이 구리–구리, 절연막–절연막을 직접 접합 | 차세대(HBM4E/HBM5 검토) | 스택 높이↓·방열↑·피치 미세화, 대신 **초청정·초평탄(CMP)** 필요 |

- **삼성 HBM4 (뉴스룸 2026.02):** 1c DRAM + **4나노 로직 베이스 다이**, 12단 36GB, 데이터 전송 11.7Gbps(최대 13Gbps), 전력 효율 약 40%↑, 열저항 약 10%↑, 방열 약 30%↑을 내세움.
- 삼성 기술 블로그: AI 시대 I/O 채널 수가 늘어 I/O 전력이 커지므로, **베이스 다이를 첨단 로직 공정으로** 만들어 효율을 높이는 것이 중요한 레버.
- 하이브리드 본딩: 삼성이 주도한 IEEE 논문에서 HCB 적용 시 스택 높이 약 15% 감소·열 저항 개선 보고(보도 기준). 천안에 세메스 하이브리드 본더 도입 보도.

### 4-3. 삼성 AVP 솔루션 라인업 (공식 블로그·뉴스룸)

| 브랜드 | 구조 | 핵심 내용 |
| --- | --- | --- |
| **I-Cube** (2.5D) | 인터포저 위에 로직 + HBM 수평 배치 | TSV·BEOL 기술 활용. **I-CubeS**(실리콘 인터포저), **I-CubeE**(임베디드 실리콘 브리지). I-Cube4(2021): HBM 4개 + 로직 1개, 약 100㎛ 두께 인터포저 휘어짐 제어, 몰드리스 구조로 방열 개선 |
| **H-Cube** (2021) | 고집적 기판 + 보조 기판의 하이브리드 구조 | HBM 6개 이상 대면적 패키지를 저비용으로 |
| **X-Cube** (2019) → 현 '3D Packaging' | 칩 수직 적층 | 배선 길이 단축, 대형 단일 다이 수율 리스크 감소 |
| 최신 명칭 (삼성 반도체 글로벌 블로그) | 2.5D Cube-S / 2.3D Cube-E / 2.3D Cube-R | S: 실리콘 인터포저, E: 임베디드 실리콘 브리지, R: RDL 인터포저(설계 유연·저비용) |
| 　 | 3D Cube-T / 3D Cube-H | T: **TCB 기반 CoW** 적층, H: **하이브리드 구리 본딩(HCB)** — 더 미세한 피치·전기적 성능 |

> 💡 면접 팁: 명칭이 바뀌었다는 사실까지 알면 좋지만, 본질은 \*\*"수평(2.5D)은 인터포저 종류가 성능·비용을 가르고, 수직(3D)은 본딩 방식(TCB vs HCB)이 가른다"\*\*는 구도입니다.

### 4-4. 첨단 패키지의 공통 난제 = 기계공학 문제

| 난제 | 왜 생기나 | 기계공학 도구 |
| --- | --- | --- |
| **휘어짐(Warpage)** | Si(약 3ppm/℃), 구리(약 17), EMC·기판(범위 넓음)의 CTE 차이 | 열응력 해석, 적층보 이론, FEM |
| **방열** | 12→16단 적층 + GPU 옆 고열 | 열저항 네트워크, 전도·대류 |
| **정렬 정밀도** | 범프/패드 피치 미세화 | 메카트로닉스, 제어, 비전 |
| **접합 신뢰성** | 온도 사이클링 시 반복 변형 | 피로 수명 예측, 파괴역학 |
| **얇은 칩 핸들링** | 수십 ㎛ 칩은 종이처럼 휘고 깨짐 | 그리퍼·이송 설계, 진동 제어 |

### 5-3. 공정기술 엔지니어에게 장비란?

- 장비 자체를 설계하는 것은 장비 제조사·설비기술 역할. 공정기술은 **장비의 공정 조건(레시피)을 최적화**하고, **신규 장비 평가(Eval) → 양산 적용 여부 판단**을 하며, 장비 간 편차(매칭)를 관리.
- 장비 평가 기준 예: 공정 능력(Cpk), UPH, MTBF/MTTR(고장 간격/복구 시간), 장비 간 편차, 소모품 비용, 재현성.
- 공급망 다변화(한미·세메스·ASMPT 동시 평가 보도)는 공정기술 입장에서 \*\*"서로 다른 장비로 같은 품질을 내야 한다"\*\*는 과제를 의미.

## 6. 검사·계측·불량 분석

### 6-1. 비파괴 검사 3대장

| 기술 | 원리 | 무엇을 보나 |
| --- | --- | --- |
| **AOI** (Automated Optical Inspection) | 카메라 + 영상 처리 | 표면 치핑·이물·마킹·볼 미부착·정렬 |
| **X-ray** (2D/3D CT) | X선 투과 차이 | 범프 보이드, 브리지, 와이어 스위핑, TSV 충전 |
| **SAT/SAM** (Scanning Acoustic) | 초음파 반사(음향 임피던스 차이) | 박리(Delamination), 몰드/언더필 보이드, 크랙 |

- **3D 계측:** 범프/볼 높이·동평도, 휘어짐(Shadow Moiré — 온도를 올리며 변형 측정), 웨이퍼 두께·TTV.
- \*\*공식 직무 설명의 '자동화 계측·검사'\*\*은 이런 검사를 사람 판정 없이 데이터로 판정하는 방향. 🔧 **내 연결:** 열화상 영상 기반 감지율 40→70% 개선 경험 = 비전 검사 알고리즘·조명/센서 조건 튜닝과 같은 결.

### 6-2. 파괴 분석 · 신뢰성 시험

- **단면 분석(Cross-section) + SEM/EDS(성분분석):** 불량 지점을 잘라서 직접 확인. 접합부 IMC(금속간 화합물) 두께, 크랙 경로.
- **전단/인장 시험:** Ball Shear, Wire Pull, Die Shear — 접합 강도 정량화.
- **신뢰성 시험 (JEDEC 규격 기반):**
  - **TC(Temperature Cycling):** 고온↔저온 반복 → CTE 미스매치로 인한 피로 파괴 확인
  - **HTS(High Temp Storage):** 고온 보관 → IMC 성장·열화
  - **THB / HAST:** 고온·고습·바이어스 → 부식·절연 파괴
  - **MSL / Preconditioning:** 흡습 후 리플로우 → '팝콘(popcorn) 크랙' 여부
  - **Drop / Vibration:** 낙하·진동 기계적 충격

### 6-3. 불량 분석 사고 흐름 (면접 답변 틀)

1. **현상 정의:** 어떤 불량(BIN/검사 결과)이 언제부터, 어느 장비/로트/자재에서?
2. **데이터 층별(Stratification):** 4M(Man·Machine·Material·Method)별로 나눠서 공통점 찾기. 장비 이력·자재 로트 변경 확인.
3. **물리적 확인:** 비파괴(X-ray, SAT) → 파괴(단면, SEM) 순서.
4. **가설 검증:** DOE(실험계획법)로 인자 확인.
5. **개선 및 재발 방지:** 조건 변경, SPC 관리한계 재설정, 인터락(장비 자동 정지), 표준화.

> ✅ "현상 → 층별 → 비파괴→파괴 → DOE → 재발방지" 이 흐름을 로봇팔 개선 경험(원인 분석 → 변수 변경 → 점수 개선)에 맞춰 말하는 것이 가장 안전한 답변 구조입니다.

## 7. 후기·현직자 답변에서 본 기술 면접 경향

### 7-1. 문제 형식

- **내 2026 하반기 가이드:** 직무 관련 문제풀이 후 **10분 내외 발표 + 질의응답** (후기보다 가이드 우선).
- 2023 하반기 이후: 대주제 3개 중 1개 선택 → 소문제 3개, 약 15분 풀이 → 설명 → 꼬리질문.
- 소문제 구성(후기 공통): ① 개념(이 공정을 왜 하나, 그림의 공정 설명) → ② 원리·변수 → ③ 실무(문제가 생기면 어떤 절차로 해결, 그때 생길 문제점).
- 현직자 답변(코멘토 2025-11): **공정 시나리오형(불량 원인·개선) / 데이터·그래프 해석형 / 직무 연관 주제형** 3가지. 난이도는 "전공 시험 1\~2번 문제", "기사 자격증 수준".

### 7-3. 꼬리질문 패턴

- "이 공정 직접 해본 적 있나요? 따로 배운 적 있나요?" → 독학이라고 솔직하게 + 공부 방법을 구체적으로(삼성 뉴스룸 8대 공정, 반도Chat, 기술 블로그 등).
- "이 공정 말고 다른 공정도 아는지?" → 인접 공정과의 연결(예: 다이싱 품질이 본딩에 미치는 영향)로 답하면 강함.
- 설명을 조금 틀리게 하면 같은 부분을 여러 번 깊게 물음(2021 하) → 모르면 "현재는 여기까지 알고, 입사 후 보완하겠다"가 오히려 합격 사례 다수.
- 자소서 경험 검증: "실험값을 어떻게 정했나", "본인이 직접 한 게 맞나" → 로봇팔 46→97점, AGV 20% 축소, 열화상 40→70%의 **측정 방법·변수·본인 역할**을 숫자로 준비.

### 7-4. 후기에서 나온 공부 조언 (기술 파트만)

- 공정마다 **정의·장단점·차세대 기술**을 기준으로 선택과 집중(2024 상).
- 외우기보다 **"왜 그렇게 되는지"와 트레이드오프**를 같이(2025 하). 예: TC-NCF vs MR-MUF, 블레이드 vs 플라즈마 다이싱, 트랜스퍼 vs 컴프레션 몰드.
- 희망 공정 하나는 한 단계 더 깊게 — 추천: **CoW 본딩(TC 본더)** 또는 **몰드/휘어짐** (로봇·구조 경험과 가장 연결됨).
- PT는 칠판에 그림 그리며 설명하는 연습이 실전에 도움.

## 8. 기술 면접 예상 질문 & 답변 스케치

> 답변은 키워드 스케치입니다. 후기 조언대로 통째 암기 말고, 흐름(정의 → 원인 → 대책 → 트레이드오프)만 익히세요.

**Q1. 패키지에서 휘어짐이 발생했다. 원인과 대책은?** ⭐ 최우선

- 원인: ① 재료 간 CTE 차이(Si·EMC·기판·구리) → 온도 변화 시 열응력 ② EMC 경화 수축 ③ 칩·몰드 두께 비대칭 ④ 공정 조건(금형 온도, 냉각 속도).
- 측정: Shadow Moiré(온도별 휘어짐 프로파일), 3D 표면 계측.
- 대책: 저CTE/고필러 EMC, 몰드 두께·칩 두께 비율 조정, 경화 프로파일 변경, 캐리어·지그로 구속, 시뮬레이션(FEM)으로 사전 예측.
- 트레이드오프: 필러↑ → CTE↓이지만 점도↑ → 충전 불량·와이어 스위핑 위험.

**Q2. TC-NCF와 MR-MUF의 차이는? 삼성은 왜 NCF인가?**

- NCF: 한 층씩 열압착, 필름이 언더필 역할 → 얇은 칩의 휘어짐 억제에 유리. 단점은 생산성·필름 두께·방열.
- MR-MUF: 일괄 리플로우 + 액상 언더필 → 생산성·방열 유리. 고단·박형에서 휘어짐 제어가 과제.
- 안전한 마무리: "각각 장단이 있고, 차세대는 양쪽 모두 하이브리드 본딩을 검토 중이라고 알고 있다." (타사 비하는 말 금지)

**Q3. 하이브리드 본딩이란? 왜 어렵나?**

- 범프 없이 Cu–Cu + 절연막–절연막 직접 접합 → 피치 미세화, 스택 높이↓, 방열↑.
- 어려움: 표면 입자·오염(보이드), 평탄도(CMP 로 Cu 리세스 제어), 정렬 정밀도, 다이싱 입자 → 플라즈마/레이저 다이싱 검토(삼성 발표 보도).
- 연결: "전공정 수준의 청정도·평탄도가 후공정에 들어오는 것"이라는 관점.

**Q4. 본딩 후 스트립 한쪽 끝에서만 접합 불량이 많다. 어떻게 분석하나?** (구역별 불량 시나리오)

- 위치 의존 → 장비 측 요인 우선 의심: 헤드–스테이지 평행도, 스테이지 온도 분포, 기판 휘어짐(가장자리 들림), 진공 흡착 불균일.
- 확인: 장비별/자재 로트별 층별 → 온도 매핑·감압지 테스트 → X-ray/단면 → 조건 변경 후 재현 실험(DOE).
- 연결: 로봇팔 정밀도 개선처럼 "기구·조건·측정 중 어디서 오차가 오나"를 나눠서 봤던 경험.

**Q5. 와이어 본딩과 플립칩의 차이, 언더필의 역할은?** → 2-4절 표. 언더필 = CTE 차이 열응력을 분산해 범프 피로 수명 연장.

**Q6. 테스트 수율이 갑자기 떨어졌다. 그래프를 보고 무엇을 확인하나?**

- 본인 불량 인지, 테스트 장비 문제인지 구분이 먼저: 특정 테스터/소켓/핸들러에만 몰려 있나? 재테스트 시 양품이 되나?(소켓 접촉 불량)
- 반도체 불량이면 BIN 분포로 유형 파악 → 앞 공정(본딩·몰드) 로트 역추적.
- 연결: 열화상 연구에서 "제품 문제인지 측정 환경 문제인지" 구분한 경험(자소서 문장과 동일).

**Q7. 다이싱 방식을 비교하고, 얇은 웨이퍼에는 무엇이 좋은가?** → 2-2절 표. 얇을수록 블레이드 치핑·크랙 위험 → 스텔스/플라즈마, DBG.

**Q8. Burn-in은 왜 하나? 테스트 비용을 줄이려면?**

- 욕조 곡선 초기 고장 제거. 비용 절감: 동시 측정 수↑, MBT로 번인+테스트 통합, 테스트 항목 최적화(데이터 기반), 핸들러 잼률·인덱스 타임 감소, 자동화.

**Q9. HBM 적층 수가 늘어날수록 TSP에 생기는 문제는?**

- 수율 곱셈(KGD 중요), 얇은 칩 핸들링·휘어짐, 방열, JEDEC 높이 제한 → 본딩층 박막화/HCB, 본딩 시간 증가(생산성).

**Q10. 기계공학 전공자로서 TSP에 어떻게 기여할 수 있나?**

- "후공정의 난제(휘어짐·크랙·접합·열·정렬)는 재료역학·열전달·제어의 문제" + 구체 연결 세 개: 로봇팔 정밀도 → 본더·핸들러, AGV 구조 설계·정적 해석 → 지그·캐리어·휘어짐, 열화상 비전 → 자동 검사.
