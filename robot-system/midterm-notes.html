3. 위치·자세 표현과 좌표변환

오른손 좌표계 (RHS)

  1. 오른손 엄지가 +Z 방향
  2. 손가락을 감는 방향이 X축 → Y축
  3. Z축 위에서 보면 반시계 방향

Roll-Pitch-Yaw: x축 회전 = Roll, y축 회전 = Pitch, z축 회전 = Yaw

Frame {B} = { ABR, APB } : 자세(회전행렬) + 원점 위치의 쌍

평행이동 · 회전 · 역행렬

평행이동만:  AP = BP + APB
회전만(원점 같음):  AP = ABR · BP
역회전:  BAR = ABR−1 = ABRT   (회전행렬은 직교행렬: RRᵀ = I, det R = 1)
시험 포인트ABR의 각 열은 {B}의 x, y, z 단위벡터를 {A}에서 본 성분입니다. 회전행렬의 역은 전치로 구하므로 계산할 필요가 없습니다.

기본 회전행렬 (외우기)

RX(γ) =1000cγ−sγ0sγcγ RY(β) =cβ0sβ010−sβ0cβ RZ(α) =cα−sα0sαcα0001

RY만 −s가 왼쪽 아래에 있습니다(z×x = y 순서 때문). 자주 틀리는 부분입니다.

예제 3-1 · 회전만 있는 경우
{B}가 {A}에 대해 z축으로 90° 회전. BP = (2, 0, 0)일 때 AP는?
AP =0−10100001200=020
답 AP = (0, 2, 0). {B}의 x축이 {A}의 y축과 같은 방향이므로 그림과 일치합니다. 거꾸로 BP = Rᵀ·AP = (2, 0, 0)으로 돌아옵니다.

Z-Y-X Euler 각 (움직이는 좌표축 기준)

z축으로 α → 새로 생긴 y축으로 β → 새로 생긴 x축으로 γ 회전. 움직이는 축 기준 회전은 오른쪽으로 곱해 나갑니다.

ABRZ'Y'X'(α, β, γ) = RZ(α) · RY(β) · RX(γ)
=cαcβcαsβsγ − sαcγcαsβcγ + sαsγsαcβsαsβsγ + cαcγsαsβcγ − cαsγ−sβcβsγcβcγ
시험 포인트움직이는 축(Euler) 기준이면 R = R1·R2·R3 (오른쪽 곱), 고정 축 기준이면 R = R3·R2·R1 (왼쪽 곱). 그래서 Z-Y-X Euler 각은 X-Y-Z 고정각과 같은 행렬이 됩니다.
예제 3-2 · Euler 각 (90°로 단순화)
움직이는 축 기준으로 z축 90°, 새 y축 90°, 새 x축 0° 회전했을 때 ABR은?
RZ(90°)RY(90°) =0−10100001001010−100=0−10001−100
답 공식에 α=90°, β=90°, γ=0°를 넣어도 같은 결과입니다(cα=0, sα=1, cβ=0, sβ=1, cγ=1, sγ=0). 검산으로 x열×y열 = (0,0,−1)×(−1,0,0) = (0,1,0) = z열이 나오면 오른손 좌표계가 맞습니다.

강의 예제(z 30°, y 45°, x 60°)도 같은 방법으로, 위 공식에 cα=√3/2, sα=1/2, cβ=sβ=√2/2, cγ=1/2, sγ=√3/2를 대입하면 됩니다. 예: r31 = −sβ = −√2/2, r33 = cβcγ = √2/4.

동차변환 (Homogeneous Transform)

AP = ABR · BP + APB = ABT · BP
ABT =ABR (3×3)APB (3×1)0 0 01

위치벡터는 (x, y, z, 1)처럼 1을 붙인 4×1로 씁니다. 마지막 행이 [0 0 0 1]이 아니거나 R이 정규직교가 아니면 올바른 동차변환이 아닙니다.

합성과 역변환

합성: AP = ABT · BCT · CP   (아래첨자·위첨자가 이어지도록 곱함)
역변환: BAT = ABT−1 = [ Rᵀ   −Rᵀ·APB ; 0 0 0 1 ]
자주 나오는 실수역변환의 위치 부분은 그냥 −P가 아니라 −Rᵀ·P입니다.

동차변환의 세 가지 해석

  1. Description of a frame: {B}가 {A}에 대해 어디 있고 어느 방향인지 기술
  2. Transform mapping: BP → AP 로 좌표계를 바꿔 표현
  3. Transform operator: 같은 좌표계 안에서 점을 이동시킴, AP2 = T · AP1

평면 2R(3R) 역기구학 공식

① θ2 (코사인 법칙):
x² + y² = L1² + L2² + 2L1L2·c2  ⇒  c2 = (x² + y² − L1² − L2²) / (2L1L2)
s2 = ±√(1 − c2²),   θ2 = Atan2(s2, c2) (± 두 개 → elbow 두 해)

② θ1 (대수적): k1 = L1 + L2·c2,   k2 = L2·s2
x = k1·c1 − k2·s1,   y = k1·s1 + k2·c1  ⇒  θ1 = Atan2(y, x) − Atan2(k2, k1)

③ 3R이면: θ3 = φ − θ1 − θ2  (φ = 원하는 끝단 방향)

강의 슬라이드에 k2 = l2로 적힌 곳이 있는데, 위 식 x = k1c1 − k2s1이 성립하려면 k2 = L2·s2입니다.

기하적 방법: θ1 = β ± ψ, β = Atan2(y, x), ψ는 삼각형(L1, L2, r)에서 코사인 법칙으로 cos ψ = (x² + y² + L1² − L2²) / (2L1·√(x²+y²))

해가 없는 경우|c2| > 1이면 목표점이 너무 멀거나 가까운 것입니다. 2R의 reachable workspace는 |L1 − L2| ≤ r ≤ L1 + L2 인 고리 모양이고, L1 = L2이면 원점까지 닿습니다.

6. 자코비안: 속도와 정적 힘

정의

Y = F(X) 이면   δY = (∂F/∂X)·δX = J(X)·δX  J의 (i, j) 원소 = ∂fi/∂xj
로봇:   ẋ = J(θ)·θ̇    θ̇ = J−1(θ)·ẋ (J가 정방이고 비특이일 때)
  • ẋ = (vx, vy, vz, ωx, ωy, ωz): 끝단 선속도 + 각속도, 6×1
  • J는 6×n 행렬 (n = 관절 수), θ̇는 n×1
  • J는 θ에 따라 변하는 시변 선형변환입니다
  • 특이점(singularity): det J = 0이 되어 역변환이 안 되는 자세. 끝단이 어떤 방향으로는 움직일 수 없음

자코비안 구하는 두 방법: ① 정기구학 식을 시간으로 미분 ② 링크 속도를 차례로 전파(recursive velocity propagation)

SELF CHECK

7. 단답 셀프체크

질문을 눌러 답을 확인하세요.

Kinematics와 Dynamics의 가장 큰 차이는?

Kinematics는 힘·토크를 고려하지 않고 위치·속도·가속도만 다루고, Dynamics는 힘·토크와 가속도의 관계를 다룬다.

Open chain과 Closed chain을 경로 개수로 구분하면?

Open: 베이스에서 끝단까지 경로가 하나. Closed: 링크끼리 두 개 이상의 경로로 연결.

병렬 매니퓰레이터가 직렬보다 유리한 점 세 가지는?

강성이 높고, 오차 누적이 적어 정밀하며, 무거운 하중을 지지하기 좋다. (단점: 작업공간이 좁고 해석·제어가 복잡)

SCARA의 "Selective Compliance"는 무슨 뜻인가?

평면 방향(평행한 회전 관절)으로는 유연하고, 수직 방향으로는 강성이 높아 조립 작업에 유리하다는 뜻.

Reachable workspace와 Dexterous workspace의 차이는?

Reachable: 최소 한 가지 자세로 도달 가능한 점. Dexterous: 모든 자세로 도달 가능한 점. Dexterous ⊂ Reachable.

Redundant robot이란?

작업에 필요한 자유도(3D에서 6)보다 관절 자유도가 많은 로봇. 역기구학 해가 연속적으로 무수히 많다.

회전행렬의 역행렬은 어떻게 구하나?

전치하면 된다. R−1 = Rᵀ (직교행렬).

동차변환 역행렬의 위치 부분은?

−Rᵀ·P. 그냥 −P가 아니다.

Z-Y-X Euler 각의 행렬 곱 순서는?

RZ(α)·RY(β)·RX(γ). 움직이는 축 기준이므로 오른쪽으로 곱한다.

Craig DH에서 ai−1과 di는 각각 어느 축을 따라 재나?

ai−1: Xi−1을 따라 Zi−1→Zi 거리. di: Zi를 따라 Xi−1→Xi 거리.

회전 관절과 직선 관절의 DH 변수는?

회전(R): θi. 직선(P): di.

역기구학 해석적 방법과 수치적 방법의 특징은?

해석적(대수/기하): 식으로 바로 계산, 모든 해 가지를 찾을 수 있음. 수치적(반복): 초기값에서 오차를 줄여 감, 보통 해 하나, 초기값·수렴성이 중요.

2R 로봇에서 θ2의 해가 두 개 나오는 이유는?

s2 = ±√(1 − c2²)에서 부호가 두 개라서. elbow-up / elbow-down.

ẋ = Jθ̇에서 J의 크기는?

6×n (끝단 선속도 3 + 각속도 3, n = 관절 수).

특이점에서는 무슨 일이 생기나?

det J = 0이라 J−1이 없고, 끝단이 특정 방향으로 움직일 수 없다. 2R은 θ2 = 0° 또는 180°.

끝단 힘과 관절 토크의 관계식은?

τ = Jᵀ(θ)·F

회전 관절 i의 자코비안 열은?

선속도 부분 zi−1 × (pe − pi−1), 각속도 부분 zi−1. 직선 관절이면 [zi−1; 0].
