1. 개론·시스템 Week 1–2

  • 로봇 정의: 감지(sensing) → 계산(판단) → 행동(action)하는 자율 기계
  • 흐름: Automation → Autonomy → Popularization → Collaboration → Intelligence
  • Cartesian PPP · Cylindrical RPP · SCARA(평면 유연, 수직 강성) · Articulated(회전 ≥3) · Delta(병렬, 고속, 고가)
  • Open chain = 경로 1개(직렬) / Closed chain = 경로 2개 이상(병렬)
  • 병렬: 강성↑ 정밀↑ 하중↑, 작업공간↓, 해석·제어 복잡
  • Kinematics = 힘 무시(위치·속도) / Dynamics = 힘·토크 ↔ 가속도
  • Reachable(한 자세라도) ⊃ Dexterous(모든 자세)
  • DOF = 변수 수 − 독립 구속식 수. 6 = 일반, 6 초과 = Redundant, 6 미만 = Deficient
  • FK·IK·Jacobian·동역학·궤적·제어의 Given / Compute 구분
  • Joint space ↔ Cartesian(Task) space: FK는 →, IK는 ←
  • 센서: 엔코더(증분=상대, 절대=절대 위치), 타코(속도), F/T(힘·모멘트), LiDAR(거리·3D)

2. 좌표변환 Week 3

  • ᴬR_B의 각 열 = {B}의 x, y, z 축을 {A}에서 본 것
  • R⁻¹ = Rᵀ (직교, det = 1)
  • R_X, R_Y, R_Z 기본행렬. R_Y만 −s가 왼쪽 아래
  • 움직이는 축(Euler) = 오른쪽 곱 R1R2R3 / 고정 축 = 왼쪽 곱 R3R2R1
  • Z-Y-X Euler = X-Y-Z Fixed (같은 행렬)
  • 동차변환 역: 위치부는 −Rᵀ·P
  • T의 세 해석: 프레임 기술 · 좌표 매핑 · 연산자
ᴬP = ᴬR_B·ᴮP + ᴬP_B = ᴬT_B·ᴮP ᴮT_A = [ Rᵀ −RᵀP ; 0 0 0 1 ] ᴬP = ᴬT_B · ᴮT_C · ᶜP

3. DH (Craig) Week 4–5

  • ai−1: Zi−1→Zi 거리, Xi−1 따라 · αi−1: 같은 축 기준 비틀림
  • di: Xi−1→Xi 거리, Zi 따라 · θi: 같은 축 기준 회전
  • 회전 관절이면 θ가 변수, 직선 관절이면 d가 변수
  • {i}는 관절 i에 붙음(Craig). Standard는 링크 끝(다음 관절)에 붙음
  • Craig 2R: L1은 2번 줄, 끝단까지 가려면 E 줄 추가
  • 평행 축 → α = 0, 수직 축 → α = ±90°, 축이 만나면 a = 0
  • PUMA 560 표 형태(α: 0, −90, 0, −90, 90, −90)

6. 자코비안 Week 6-2

  • ẋ = Jθ̇, J는 6×n (선속도 3 + 각속도 3)
  • J의 i열 = 관절 i만 돌릴 때 끝단 속도 (관절→끝단에 수직, 크기 = 거리)
  • 평면 지름길: 관절→끝단 (X, Y) → 열 (−Y, X)
  • 열 공식: R → [z × (p_e − p); z], P → [z; 0]
  • 2R·3R 평면: det J = L1L2·sin θ2 → θ2 = 0°, 180° 특이점
  • 특이점: 두 열이 나란, J⁻¹ 없음, 팔 길이 방향으로 못 움직임
  • τ = JᵀF (힘 × 작용선까지 수직 거리)
  • Ṙ = S(ω)R, S(ω)r = ω × r (반대칭 행렬)
  • 2×2 역행렬: 1/(ad−bc)·[d −b; −c a]
J_2R = [ −L1s1−L2s12 −L2s12 ] [ L1c1+L2c12 L2c12 ] J_3R = 1열(L1,L2,L3 항) | 2열(L2,L3) | 3열(L3), 마지막 줄 [1 1 1]
