자코비안 그림 예제

평면 로봇, 링크 길이는 모두 1입니다. 문제 그림을 보고 풀고, 바로 아래 정답 상자에서 풀이 그림과 계산을 확인하세요.

J 열 = (관절→끝단 벡터 (X,Y)) 를 90° 돌린 (−Y, X)  |  v = Jθ̇  |  θ̇ = J⁻¹v  |  τ = JᵀF

11R 로봇의 끝단 속도

길이 r = 2인 1R 로봇이 θ = 90°(위를 향함)에서 θ̇ = 1 rad/s로 반시계 방향으로 돈다. 끝단 속도 (ẋ, ẏ)는?

답: v = (−2, 0)

ẋ = −r·sin θ·θ̇ = −2·1·1 = −2 ẏ = r·cos θ·θ̇ = 2·0·1 = 0

링크(위쪽)에 수직인 방향은 왼쪽이고, 크기는 v = rω = 2·1 = 2입니다.

2J의 열을 그림으로 구하기

2R 로봇, θ1 = 90°, θ2 = 90°. 끝단은 (−1, 1)에 있다.

  1. 각 관절에서 끝단까지 벡터를 이용해 J의 두 열을 구하라.
  2. θ̇ = (1, 1)일 때 끝단 속도는?

답: J = [−1 0; −1 −1], v = (−1, −2)

관절1 (0,0) → 끝단: (−1, 1) → 90° 돌리면 (−1, −1) = 1열 관절2 (0,1) → 끝단: (−1, 0) → 90° 돌리면 ( 0, −1) = 2열 J = [ −1 0 ] v = (−1,−1) + (0,−1) = (−1, −2) [ −1 −1 ]

식으로 확인: s1 = 1, c1 = 0, s12 = sin180° = 0, c12 = −1 → J = [−1−0, −0; 0−1, −1] ✓

3원하는 방향으로 움직이기 (역속도)

문제 2와 같은 자세에서 끝단을 오른쪽으로 v = (1, 0) 움직이고 싶다. θ̇1, θ̇2는?

답: θ̇ = (−1, 1)

det J = (−1)(−1) − (0)(−1) = 1 J⁻¹ = 1/1 · [ −1 0 ] θ̇ = J⁻¹·(1, 0) = (−1, 1) [ 1 −1 ]

그림으로: 1열 (−1, −1)을 −1배 하면 (1, 1), 2열 (0, −1)을 1배 더하면 (1, 0). 관절 1을 시계 방향으로 돌리면 오른쪽 위로 가고, 관절 2가 위쪽 성분을 상쇄합니다.

검산: J·(−1, 1) = (1 + 0, 1 − 1) = (1, 0) ✓

4물건을 들고 버티는 토크

문제 2와 같은 자세에서 끝단에 아래로 2 N의 하중이 걸린다. 끝단이 버티려면 로봇이 내야 하는 힘은 F = (0, 2)이다. 관절 토크 τ1, τ2는?

답: τ = (−2, −2) N·m

Jᵀ = [ −1 −1 ] τ = Jᵀ·(0, 2) = (−2, −2) [ 0 −1 ]

그림으로: 힘의 작용선은 x = −1인 세로선입니다. 관절 1(원점)과 관절 2(0, 1)는 둘 다 이 선에서 수평으로 1만큼 떨어져 있습니다. 그래서 두 관절 모두 크기 1 × 2 = 2의 토크가 필요합니다. 부호가 음수(시계 방향)인 것은 끝단이 두 관절보다 왼쪽에 있어서, 그곳을 위로 밀려면 관절이 시계 방향으로 비틀어야 하기 때문입니다.

5팔을 위로 쭉 편 자세

2R 로봇, θ1 = 90°, θ2 = 0°. 끝단은 (0, 2)에 있다.

  1. J와 det J를 구하라.
  2. 끝단이 움직일 수 없는 방향은?

답: J = [−2 −1; 0 0], det J = 0 (특이점), 위아래(y) 방향 불가

s1 = 1, c1 = 0, s12 = 1, c12 = 0 J = [ −1−1 −1 ] = [ −2 −1 ] det = (−2)(0) − (−1)(0) = 0 [ 0+0 0 ] [ 0 0 ]

두 열 (−2, 0), (−1, 0)이 둘 다 왼쪽을 향합니다(나란함). 어떻게 섞어도 y 성분이 0이라 팔 길이 방향(위아래)으로는 움직일 수 없습니다. 일반식으로도 det J = L1L2·sin θ2 = sin 0° = 0입니다.

6수평으로 뻗은 팔의 토크

2R 로봇, θ1 = 0°, θ2 = 0°(오른쪽으로 쭉 폄, 끝단 (2, 0)).

  1. 끝단에서 위로 F = (0, 1)을 낼 때 τ는?
  2. 끝단에서 오른쪽으로 F = (1, 0)을 낼 때 τ는?

답: ① τ = (2, 1)   ② τ = (0, 0)

J = [ 0 0 ] Jᵀ = [ 0 2 ] [ 2 1 ] [ 0 1 ] ① Jᵀ·(0, 1) = (2, 1) ② Jᵀ·(1, 0) = (0, 0)

① 위로 미는 힘: 어깨는 거리 2, 팔꿈치는 거리 1 → 어깨가 두 배로 힘듭니다.

② 팔 방향으로 미는 힘은 모든 관절을 지나가는 작용선 위에 있어서 토크 0. 특이 자세에서는 그 방향 힘을 구조(링크)가 그대로 받아냅니다.

7평면 3R의 자코비안

3R 로봇, θ1 = 0°, θ2 = 90°, θ3 = −90°. 관절은 (0,0), (1,0), (1,1)에 있고 끝단은 (2, 1)이다. 출력 (ẋ, ẏ, α̇)에 대한 3×3 자코비안을 그림으로 구하라.

답: J = [−1 −1 0; 2 1 1; 1 1 1]

관절1 (0,0)→끝단 (2,1) → (−1, 2) 관절2 (1,0)→끝단 (1,1) → (−1, 1) 관절3 (1,1)→끝단 (1,0) → ( 0, 1) 각속도 줄 α̇ = θ̇1+θ̇2+θ̇3 → (1, 1, 1) J = [ −1 −1 0 ] [ 2 1 1 ] [ 1 1 1 ]

공식 확인: s1 = 0, c1 = 1, s12 = 1, c12 = 0, s123 = 0, c123 = 1 → 1행 (−0−1−0, −1−0, −0), 2행 (1+0+1, 0+1, 1) ✓

8속력만 빨리 구하기

2R 로봇, θ1 = 0°, θ2 = 90°(끝단 (1, 1)). 관절 1만 2 rad/s로 돌릴 때 끝단의 속력과 방향은? (J를 다 쓰지 말고 v = rω로)

답: 속력 2√2, 방향 (−1, 1) (왼쪽 위 45°)

r = |(1, 1)| = √2, v = r·ω = √2 · 2 = 2√2 방향: (1, 1)을 90° 돌린 (−1, 1) → v = 2·(−1, 1) = (−2, 2)

J의 1열 (−1, 1)에 θ̇1 = 2를 곱한 것과 같습니다.
