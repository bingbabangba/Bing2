역기구학 θ1 그림 풀이

θ1 = Atan2(y, x) − Atan2(k2, k1)이 왜 성립하는지 세 컷으로 봅니다. 핵심은 하나입니다. 팔꿈치 각 θ2를 고정하면, 팔 전체는 하나의 막대처럼 원점을 중심으로 θ1만큼 돌 뿐입니다.

세 컷으로 보는 증명

예: L1 = L2 = 1, θ2 = 90°, θ1 = 45°

① 링크 1을 x축에 눕혀서 본다

θ1 = 0으로 놓으면 끝단 좌표가 바로 보입니다. 가로 k1 = L1 + L2·c2, 세로 k2 = L2·s2. 이 점의 각도가 γ = Atan2(k2, k1)입니다.

② 팔 전체를 θ1만큼 돌린다

θ2가 그대로라 팔 모양은 안 변합니다. 끝단은 원점에서 같은 거리 r을 유지한 채 원을 따라 θ1만큼 이동합니다.

③ 각도만 비교한다

실제 끝단 방향 β = Atan2(y, x)는 원래 방향 γ에 θ1이 더해진 값입니다.

β = γ + θ1  ⇒  θ1 = Atan2(y, x) − Atan2(k2, k1)

직접 돌려 보기

슬라이더를 움직여 보세요. θ1을 바꾸면 β만 변하고 k1, k2, γ는 그대로입니다. θ2를 바꾸면 그 반대입니다. 맨 아래 줄 β − γ는 항상 θ1과 같습니다.

값식지금
k1L1 + L2·cos θ2
k2L2·sin θ2
γAtan2(k2, k1)
(x, y)실제 끝단
βAtan2(y, x)
β − γ= θ1 이어야 함

숫자 예제: L1 = L2 = 1, 목표 (0, √2)

목표가 y축 위에 있으므로 β = Atan2(√2, 0) = 90°입니다. 두 해 모두 β는 같고, γ만 다릅니다.

c2 = (x² + y² − L1² − L2²)/(2L1L2) = (0 + 2 − 1 − 1)/2 = 0 → s2 = ±1, θ2 = ±90°

해 1: θ2 = +90°

k1 = 1 + 1·cos 90° = 1 k2 = 1·sin 90° = 1 γ = Atan2(1, 1) = 45° θ1 = 90° − 45° = 45°

링크 1 기준으로 끝단이 45° 위에 있으니, 팔 전체를 45°만 더 돌리면 90° 방향에 닿습니다.

해 2: θ2 = −90°

k1 = 1 + 1·cos(−90°) = 1 k2 = 1·sin(−90°) = −1 γ = Atan2(−1, 1) = −45° θ1 = 90° − (−45°) = 135°

이번엔 끝단이 링크 1보다 45° 아래에 있으니, 팔 전체를 135°까지 돌려야 90° 방향에 닿습니다.

검산 해 1 (45°, 90°): x = cos45° + cos135° = √2/2 − √2/2 = 0, y = sin45° + sin135° = √2/2 + √2/2 = √2 ✓ 검산 해 2 (135°, −90°): x = cos135° + cos45° = 0, y = sin135° + sin45° = √2 ✓
