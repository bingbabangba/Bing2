자코비안 그림 풀이

평면 2R 로봇(L1 = L2 = 1)으로 봅니다. 자코비안 ẋ = J θ̇은 "관절을 이만큼 빨리 돌리면 끝단이 어느 방향으로 얼마나 빨리 가나"를 알려주는 표입니다.

J의 i번째 열 = 관절 i만 1 rad/s로 돌릴 때 끝단 속도.
그 속도는 (관절 i → 끝단) 선에 수직이고, 크기는 그 거리와 같습니다. (v = rω)

① 열 하나씩 보기

자세: θ1 = 0°, θ2 = 90° (끝단 (1, 1)). 예제 6-2와 같은 자세입니다. 속도 화살표는 보기 좋게 1/2 크기로 그렸습니다.

관절 1만 돌리기 → 1열

팔 전체가 원점을 중심으로 돕니다. 원점→끝단 거리 √2, 방향은 그 선에 수직 → (−1, 1)

관절 2만 돌리기 → 2열

링크 2만 관절 2를 중심으로 돕니다. 관절2→끝단은 (0, 1)이고 거리 1, 수직 방향 → (−1, 0)

둘 다 돌리기 → 더하기

θ̇ = (1, 1)이면 두 화살표를 더한 (−2, 1). 이게 바로 J θ̇ 계산입니다.

J = [ −1 −1 ] J·(1, 1) = 1·(−1, 1) + 1·(−1, 0) = (−2, 1) [ 1 0 ] 1열 2열

일반식 J = [−L1s1−L2s12, −L2s12; L1c1+L2c12, L2c12]도 같은 원리입니다. (관절 → 끝단) 벡터가 (X, Y)일 때 수직 방향은 (−Y, X)이므로, 1열은 (−y, x), 2열은 링크 2 부분만의 (−Y, X)입니다.

② 직접 돌려 보기

초록 타원은 관절 속도의 크기를 1로 제한했을 때 끝단이 낼 수 있는 모든 속도입니다. 둥글수록 모든 방향으로 잘 움직이고, θ2를 0°나 180° 쪽으로 보내면 납작해집니다.

③ 특이점: 두 열이 나란해질 때

두 열(주황, 보라)이 서로 다른 방향이면 둘을 섞어 어떤 방향이든 만들 수 있습니다. 둘이 같은 선 위에 놓이면 그 선 방향으로만 움직일 수 있습니다. 이때 det J = L1L2·sin θ2 = 0입니다.

θ2 = 90° det = 1

두 열이 충분히 벌어져 있음. 타원이 통통함.

θ2 = 30° det = 0.5

두 열이 가까워짐. 팔 길이 방향으로 움직이기 어려워짐.

θ2 = 0° det = 0

두 열이 둘 다 위 방향. 타원이 선이 됨. x 방향(팔 길이 방향)으로는 못 움직임.

④ 거꾸로 쓰기: 역속도와 정적 힘

θ̇ = J⁻¹v : 원하는 속도를 두 열로 쪼개기

끝단을 위로 v = (0, 1) 움직이고 싶다. 1열 (−1, 1)을 1배, 2열 (−1, 0)을 −1배 하면 왼쪽 성분이 상쇄되고 위쪽만 남습니다.

1·(−1, 1) + (−1)·(−1, 0) = (0, 1) → θ̇ = (1, −1) (J⁻¹ 계산과 같은 답)

τ = JᵀF : 힘 × 수직 거리 = 토크

끝단에서 위로 F = (0, 1)을 내려면, 각 관절은 힘의 작용선까지의 수직 거리 × 힘만큼 토크를 내야 합니다.

관절 1: 작용선(x = 1)까지 거리 1 → τ1 = 1 관절 2: 작용선 위에 있음, 거리 0 → τ2 = 0 Jᵀ·(0, 1) = (1, 0) ✓

Jᵀ의 각 행은 J의 각 열이므로, τi = (i번째 열) · F입니다. 관절 i만 돌렸을 때 끝단이 움직이는 방향으로 힘이 얼마나 작용하는지를 재는 것과 같습니다. 힘과 그 방향이 수직이면 관절은 힘을 버티지 않아도 됩니다(τ = 0).
