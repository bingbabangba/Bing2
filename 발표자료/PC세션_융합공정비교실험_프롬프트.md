## 0. 먼저 확인해 주세요 (작업 전)
1. 기존 단일 계조 모델과 다중 계조(A+B+C) 모델의 학습 설정: 에폭 수, 배치 크기, 총 반복(iteration) 수, 학습 시간. 다중 계조 모델이 단일 모델보다 반복 수가 3배였는지 확인.
2. 다중 계조 모델의 학습 영상 구성: 같은 장면의 A·B·C를 모두 넣었는지(3N장), 라벨은 같은지.
3. 융합 방식(점수 순 NMS 등)과 IoU 문턱 값.

## 1. 비교 조건
N = 학습 장면 수(3,077장), T = 단일 계조 모델의 총 반복 수. 단일 계조 대표는 C(최고 단일)를 기본으로 하고, 가능하면 B도 함께 해 주세요.

| 기호 | 조건 | 학습 영상 | 학습 반복 | 추론 횟수 | 모델 수 | 새 학습 | 확인하려는 것 |
|---|---|---|---|---|---|---|---|
| S | 단일 C (기존) | N | T | 1 | 1 | 없음 | 기준 |
| S-long | 단일 C, 반복 3배 (3T) | N | 3T | 1 | 1 | 필요 | 학습량만 늘리면 좋아지나 |
| S-TTA | 단일 C + 테스트 시 증강 3회(원본·좌우반전·스케일 등) 후 같은 방식으로 융합 | N | T | 3 | 1 | 없음 | "3번 보고 합치기"만으로 좋아지나 |
| E-same | 같은 계조 C 모델 3개(시드 다름) 앙상블 (기존) | N | 3T | 3 | 3 | 없음 | 계산량을 맞춘 앙상블 |
| E-cross | 단일 A·B·C 모델 3개를 각자 계조로 추론 후 융합 | N | 3T | 3 | 3 | 없음 | 계조 다양성 + 앙상블 |
| M-1 | 다중 계조 모델에 A·B·C 중 하나만 입력 | 3N | 기존 | 1 | 1 | 없음 | 학습 데이터 3배 효과만 |
| M-eq | 다중 계조 모델을 반복 T로 학습(단일과 같은 계산량) + 융합 | 3N | T | 3 | 1 | 필요 | 계산량을 맞춰도 좋은가 |
| M | 다중 계조 + 융합 (제안, 기존) | 3N | 기존 | 3 | 1 | 없음 | 제안 방식 |

- 새 학습이 필요한 S-long, M-eq는 시드 3개씩(총 6회). 나머지는 기존 가중치로 추론만.
- 모든 조건은 같은 초기 가중치, 같은 판정 기준(점수 ≥ 0.4, IoU ≥ 0.5), 같은 융합 방식.

## 2. 평가셋 (모두 기존과 동일, 학습 미사용)
- 실험 ①: 다른 건물·날짜 소화기 281 / 계단 626 / 문 166장 (대규모 학습 기준)

## 3. 분석
1. 조건별 탐지율(시드 평균 ± 시드별 값)과 오탐 장 수 표
2. M 대 S-long, M 대 M-eq, M 대 E-cross, M-eq 대 S-long: 시드별 McNemar 검정 + 부트스트랩 95% 신뢰구간
3. 조건별 학습 시간, 프레임당 추론 시간(ms)
4. 해석: 아래 중 어느 경우인지 판단
   - M-eq ≈ M 이고 S-long, S-TTA보다 높음 → 성능 향상은 학습량이 아니라 계조 다양성과 융합 덕분
   - S-long ≈ M → 학습량 효과가 큼 (포스터 주장 수정 필요)
   - E-cross ≈ M → 계조 융합이 핵심, 제안 방식의 장점은 모델 1개(메모리)
   - S-TTA ≈ M → 단순히 여러 번 보고 합치는 효과
