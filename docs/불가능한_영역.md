# 클라우드 작업 환경에서 실제 게임을 못 돌린 이유 (2026-10-25 직접 확인)

요청: "실제 게임 실행부터 뽑기까지 진행". 이 작업 환경(Claude 클라우드 컨테이너)에서 끝까지 시도한 결과입니다.

| 단계 | 결과 | 확인 내용 |
|---|---|---|
| 게임 받기 (PC/안드로이드) | **불가** | hsr.hoyoverse.com, 패치 서버, Google Play, APKPure, APKMirror 모두 네트워크 정책에서 차단(403) |
| 에뮬레이터/이미지 받기 | **불가** | dl.google.com(SDK), waydro.id, bluestacks, qemu, sourceforge 차단 |
| Waydroid / Redroid / Anbox | **불가** | 커널에 binder 없음(`CONFIG_ANDROID_BINDER_IPC` 미설정), 모듈 로드 불가(`nomodule`) |
| 안드로이드 공식 에뮬레이터 | **불가** | 하드웨어 가속 없음(`/dev/kvm` 없음, CPU 가상화 플래그 없음, Firecracker VM 내부) |
| 3D 그래픽 | **불가** | GPU 없음(`/dev/dri` 없음). 소프트웨어 렌더링으로는 스타레일 실행 불가 수준 |
| 게임 서버 접속 | **불가** | HoYoverse API 차단. 이 환경은 HTTPS 프록시 경유만 가능해 게임용 접속이 통과하기 어려움 |
| HoYoverse 계정 가입 | **불가 (설계상 제외)** | 이메일 인증코드·캡차는 사람이 직접 입력해야 함 |

네트워크 차단은 환경 설정(Network access)에서 풀 수 있지만, binder·KVM·GPU가 없는 문제는 설정으로 해결되지 않습니다.

## 여기서 대신 해 둔 것
- ADB 멀티 에뮬레이터 실행 기능 (`run-multi`)과 에뮬레이터용 시나리오 (`scenarios/emulator_cycle.json`)
- **가짜 adb + 가짜 게임 화면으로 2대 동시 실행 검증**: 게임 실행 → 화면 인식 → 클릭 → 조이스틱 스와이프 → 스크린샷 → 워프 기록 authkey 추출 → 결과 장부·점수 기록 (`tests/test_emulator.py`)
- 몬테카를로 시뮬레이터로 경우의 수 계산 (`simulate`, `simreport`)

## 사용자 PC에서 확인이 필요한 것 (실기 미검증)
- 실제 게임 화면 템플릿 캡처와 일치도 (`check`)
- 튜토리얼 이동 구간 매크로 좌표 (`macros/emu_walk_*.json`)
- 에뮬레이터 루트 상태에서 WebView 캐시 경로(`/data/data/com.HoYoverse.hkrpgoversea`)에 기록 URL이 남는지
- 게임의 에뮬레이터·루트 감지 여부

Linux PC를 직접 갖고 있다면 Waydroid(binder 모듈 + GPU 필요)로 시도할 수 있습니다. 이 도구의 ADB 기능은 Waydroid에도 `adb connect`로 연결하면 그대로 사용할 수 있습니다.
