# 템플릿 캡처 가이드

자동화는 "화면에 이 그림이 보이면 클릭"으로 동작합니다. 게임 그림은 저작권/버전 문제로 동봉하지 않으므로 **본인 PC에서 1회 캡처**해야 합니다.

1. 게임을 **창 모드 1920x1080** (또는 16:9)로 실행, 언어는 고정.
2. 해당 화면을 띄운 상태에서 `run_admin.bat capture <이름>` → 드래그 → Enter.
   - 버튼 글자/아이콘처럼 **변하지 않는 작은 부분**만 자르세요 (배경 포함 X).
3. `run_admin.bat check` 로 현재 화면에서 일치도(0.85 이상 = O)를 확인.

| 이름 | 무엇을 자를지 |
|---|---|
| `start_tap` | 로그인 후 "클릭하여 시작" 문구 |
| `dialog_skip` | 대화 중 우상단 스킵(>>) 버튼 |
| `dialog_option` | 대화 선택지 말풍선 아이콘 |
| `skip_cutscene` | 컷신 스킵 버튼 |
| `confirm` | 팝업 "확인" 버튼 |
| `battle_auto_off` | 전투 중 꺼져 있는 "자동 전투" 버튼 |
| `tutorial_close` | 튜토리얼 안내창 닫기(X) |
| `walk_segment_1/2` | 이동이 필요한 구간의 퀘스트 문구 (이 구간은 `record`로 녹화한 매크로 재생) |
| `phone_menu_ready` | 튜토리얼 종료 후 ESC 메뉴(휴대폰) 화면의 고유 아이콘 |
| `menu_mail`, `mail_claim_all` | 휴대폰 메뉴 우편 아이콘, "모두 받기" |
| `menu_warp` | 휴대폰 메뉴 워프 아이콘 |
| `warp_x10` | "10회 워프" 버튼 (재화 부족 시 비활성 모양과 구분되게) |
| `warp_skip`, `warp_result_close` | 연출 스킵 버튼, 결과 화면 닫기(X) |
| `warp_next_banner` | 배너 목록의 다음 배너 |
| `warp_details`, `warp_records` | "상세 정보" → "기록" 탭 (authkey 생성용, 필수) |
| `menu_more`, `menu_settings`, `settings_account`, `logout_button` | 로그아웃 경로 |
| `login_screen` | 로그아웃 후 로그인 화면의 고유 부분 |

## 이동 구간 녹화
`run_admin.bat record macros/walk_1.json` → 게임에서 직접 걸어서 진행 → F12.
같은 지점에서 시작하면 재생 시 동일하게 움직입니다. 어긋나면 `until` 루프가 다음 화면을 못 찾고 타임아웃 → 스크린샷 저장 후 사람에게 넘깁니다.
