## 리세 목표 우선순위
1. **블레이드(Mortenax Blade) + 아무 좋은 상시 5성** → 최상. 지금 배너 중 신규 유저 가치가 가장 높음.
2. **펄** → 환락 딜러(은랑 LV.999, 에바네시아, 효광 등)를 함께 노릴 계획일 때만. 환락 파티가 없으면 "거르라"는 국내 리뷰가 있음.
3. **출발 워프(초보자 50뽑, 5성 확정)에서 나오는 상시 5성 순위** (Game8 리세 티어, 2026-10)
   - SS: **브로냐 > 히메코 > 웰트** (+ 4성 정운)
   - S: 게파드, 클라라, 백로 (+ 4성 페라)
   - B: 언경
4. 300뽑 누적 시 상시 5성 선택권이 있으므로 상시 캐릭터는 너무 집착하지 않아도 됨.

## 커뮤니티 공통 조언
- 리세 1회에 시간이 꽤 들고, 펄/블레이드는 몇 주간 픽업이 유지되므로 "굳이 리세 안 해도 된다"는 의견이 다수.
- 리세를 한다면 **현재 한정 5성 1장 + 좋은 상시 5성**이 현실적인 목표. 한정 5성은 싫은 캐릭터가 아니면 그냥 키우라는 조언이 많음.
- 무료 선택권(아처/길가메시, 4.7 무료 5성)은 모든 계정 공통이라 리세 판단에서 제외.
